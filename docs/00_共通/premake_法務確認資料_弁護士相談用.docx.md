**premake 法務確認資料**

**クリニック—看護師 業務委託モデル／弁護士相談用**

作成日：2026年5月18日　版：v0.9（法務確認前の叩き台）

**本資料の目的**

本資料は、アートメイク看護師と医療機関の空きスペースをつなぐ「premake」について、クリニックが看護師と業務委託契約を締結する前提で、弁護士に法的リスク・契約設計・運用設計を確認するための整理資料である。

**今回特に確認したい結論**

* クリニックが医療提供主体となり、医師が医学的判断・指示を行い、看護師が業務委託で施術を担当する建付けが可能か。  
* premake運営が、医療行為の主体・職業紹介・労働者派遣・医療広告上の広告主体等と評価されないための設計は何か。  
* 契約書、利用規約、同意書、記録管理、決済・キャンセル規定に必ず入れるべき条項は何か。

**注意：本資料内の整理は法的見解ではなく、弁護士確認前の仮説である。**

# **1\. 事業概要**

premakeは、病院・クリニック内の空き診察室・処置室・病室等と、アートメイク施術を行う看護師をつなぐ予約・業務管理・決済支援プラットフォームである。

**今回の相談では、クリニックが看護師と直接「業務委託契約」を締結し、premakeは予約・決済・業務管理システムを提供するモデルを前提とする。**

## **1.1 想定する基本モデル**

| 項目 | 主体 | 整理したい内容 |
| :---- | :---- | :---- |
| 医療提供主体 | クリニック | 患者に対する自由診療として整理できるかを確認したい。 |
| 医学的判断・指示 | クリニック所属または関与医師 | 施術可否判断、説明、指示書発行、緊急時対応方針。 |
| 施術実施者 | 看護師（クリニックとの業務委託） | 医師の指示のもとで施術。雇用ではなく業務委託で成立するか確認。 |
| 場所提供 | クリニック | 院内の空きスペースを施術場所として利用。衛生・設備・緊急時対応を確認。 |
| プラットフォーム | premake運営 | 予約、決済支援、書類管理、通知、審査補助。診断・指示・施術は行わない。 |
| 利用客 | アートメイク希望者 | クリニックの自由診療として施術を受ける想定。 |

## **1.2 premakeが「行うこと／行わないこと」**

| 区分 | 内容 |
| :---- | :---- |
| 行うこと | 予約枠管理、スペース掲載、看護師・施設アカウント管理、資格書類アップロード、決済支援、通知、記録保存補助、トラブル受付窓口 |
| 行わないこと | 診断、診察、施術可否判断、医師指示、施術、医療上の安全性保証、施術結果保証、医療機関の代替、看護師への医療上の指示 |

## **1.3 現時点の最大論点**

* 看護師は医師免許を持たないため、アートメイクを「診療の補助」として行える条件を明確にする必要がある。  
* 業務委託契約であっても、医療上の指示・監督は必要となる可能性がある。その場合、雇用上の指揮命令との線引きをどう書くべきか。  
* premakeが看護師とクリニックを結びつけるため、職業紹介・労働者派遣・募集情報等提供に該当しないか、または許認可が必要か。  
* 患者向け表示、症例写真、レビュー、看護師プロフィール等が医療広告規制に抵触しないか。

# **2\. 想定する契約関係**

業務委託モデルでは、premake運営が医療契約の当事者になりすぎないこと、かつ、クリニック・医師・看護師の責任が空白にならないことが重要である。

| 当事者 | 契約・文書 | 主な内容 | 確認したい点 |
| :---- | :---- | :---- | :---- |
| クリニック ↔ 看護師 | アートメイク施術業務委託契約 | 看護師資格、業務範囲、医師指示遵守、施術記録、衛生管理、報酬、保険、損害賠償、秘密保持、再委託禁止、解除。 | 最重要。業務委託で成立するか、実態が雇用・派遣に近づかないか確認。 |
| クリニック ↔ premake | 施設利用・プラットフォーム利用契約 | 施設掲載、予約管理、決済支援、手数料、医師・設備・衛生体制、記録保存、トラブル対応、広告表示確認。 | premakeが医療提供主体と評価されない文言が必要。 |
| 看護師 ↔ premake | 看護師向け利用規約 | アカウント、資格書類提出、予約利用、禁止事項、医師指示なし施術禁止、キャンセル、レビュー、手数料、個人情報。 | 看護師への業務指揮命令に見えないよう注意。 |
| 患者 ↔ クリニック | 自由診療契約・同意書 | 施術内容、リスク、副作用、費用、キャンセル、医師・看護師、写真・記録、個人情報、緊急時対応。 | 医療提供主体をクリニックとして明示する必要。 |
| 患者 ↔ premake | 予約・決済支援利用規約／プライバシーポリシー | 予約システム利用、通知、決済補助、個人情報、免責、問い合わせ窓口。 | premakeが施術責任を負うように見えない表現が必要。 |
| 医師 ↔ クリニック | 雇用契約・業務委託・院内規程等 | 診察、施術可否判断、指示書発行、記録確認、緊急時対応。 | 指示医が常勤でない場合の許容性・責任関係を確認。 |

## **2.1 クリニック—看護師 業務委託契約の骨子案**

* 業務範囲：アートメイク施術、事前説明補助、問診確認補助、施術記録作成、写真撮影・保存、衛生管理、術後説明補助。  
* 前提条件：有効な看護師免許、必要研修・経験、賠償責任保険、クリニックの院内規程・感染対策規程の遵守。  
* 医師指示：医師による施術可否判断・指示書発行が完了するまで施術禁止。看護師は医療上の判断を独自に行わない。  
* 記録管理：同意書、問診、施術内容、使用材料、施術前後写真、事故・副作用報告を所定様式で記録。  
* 報酬：患者支払い、クリニック売上、看護師報酬、premake手数料の流れを明記。源泉徴収・消費税・インボイス対応も確認。  
* 責任：医療判断は医師・クリニック、施術手技上の過失は看護師、施設・衛生環境はクリニック、システム障害はpremake、などの分担を検討。  
* 禁止事項：医師指示前の施術、無断キャンセル、無資格者への再委託、虚偽記録、患者情報の私的利用、SNS無断掲載。

# **3\. 責任分界案**

**以下は仮説であり、最終的な法的責任の帰属は弁護士に確認する。**

| 論点 | 一次責任の仮説 | 弁護士に確認したい点 |
| :---- | :---- | :---- |
| 施術可否判断 | 医師・クリニック | 看護師は補助情報を入力。premakeは判断しない。 |
| 医師指示書発行 | 医師・クリニック | 電子指示書の必須記載事項、電子署名要件を確認。 |
| 施術実施 | 看護師 | 業務委託で実施可能か、医師の指示・監督の程度を確認。 |
| 施術場所・衛生 | クリニック | 設備、感染対策、器具管理、廃棄物管理、緊急時体制。 |
| 患者説明・同意 | 医師・クリニック中心 | 看護師が説明補助する場合の範囲を確認。 |
| 施術記録・写真 | クリニック中心／premakeは保管補助 | 診療録等に該当するか、保存期間、閲覧権限を確認。Premakeが管理しても問題無いか確認。 |
| 決済・返金 | 契約設計に依存 | 誰が売主・役務提供者になるべきか、手数料・代理受領・返金を確認。 |
| 事故・副作用対応 | クリニック・医師中心 | 看護師の報告義務、premakeの連絡補助範囲を確認。 |
| 広告・プロフィール | 表示主体ごとに整理 | 医療広告規制、口コミ・症例写真・ビフォーアフターの扱いを確認。 |
| システム障害・情報漏えい | premake中心 | ただし医療情報の管理主体・委託関係を明確化。 |

## **3.1 premakeが医療提供主体と見られないための表現方針**

* 「premakeが施術を提供する」「premake認定で安全」「premakeが施術可否を判断」等の表現は避ける。  
* 「施術・診療・医師指示・医療上の判断は、提携医療機関および医師・看護師が行う」と明記する。  
* premakeの役割は「予約管理、決済支援、業務管理、情報連携、書類保管補助」に限定して表示する。  
* 利用客画面では、施術を行うクリニック名、担当医師または医師の関与、担当看護師、費用、キャンセル規定を明確に表示する。

# **4\. 想定運用フロー**

| \# | 工程 | 内容 |
| :---- | :---- | :---- |
| 1 | クリニック登録 | premakeにクリニック情報、施設情報、医師情報、緊急時体制、衛生管理体制を登録。 |
| 2 | 看護師登録 | 看護師免許、本人確認、実務経験、研修履歴、保険加入状況を登録。 |
| 3 | 契約締結 | クリニック—看護師間で業務委託契約。各当事者がpremake利用規約に同意。 |
| 4 | 予約枠作成 | クリニックが利用可能スペース・日時・料金を登録。看護師が枠を予約。 |
| 5 | 患者予約 | 患者が看護師の予約リンク等から予約・問診入力・同意書確認。 |
| 6 | 医師確認 | 医師が問診・必要情報を確認し、必要な診察・説明・施術可否判断を実施。 |
| 7 | 指示書発行 | 医師が施術ごとに指示書を発行。指示書未発行の場合は施術不可。 |
| 8 | 施術実施 | 看護師が医師指示・院内規程・衛生基準に従って施術。 |
| 9 | 記録保存 | 同意書、施術記録、使用材料、写真、副作用・事故の有無を記録。 |
| 10 | 決済・精算 | 患者支払い、クリニック売上、看護師報酬、premake手数料、返金を契約どおり処理。 |
| 11 | トラブル対応 | 医療上の対応はクリニック・医師、施術上の報告は看護師、システム・連絡補助はpremake。 |

## **4.1 システム上のガードレール案**

* 医師指示書が発行されていない予約は「施術実施」ステータスに進めない。  
* 看護師免許・契約・保険・院内規程同意が未完了の場合、予約受付不可。  
* 患者同意書・問診票が未完了の場合、医師確認へ進めない。  
* 施術後記録が未提出の場合、次回予約や精算を制限するか検討。  
* 事故・副作用報告は、医師・クリニック・premake運営に即時通知される設計。

# **5\. 弁護士への確認事項**

30分相談では、まず下記の優先順位で確認したい。特に「業務委託で成立するか」「premakeに許認可が必要か」「契約書で何を必ず定めるべきか」を中心に質問する。

## **5.1 最優先質問**

1\. クリニックが医療提供主体となり、看護師と業務委託契約を締結して、医師の指示のもとでアートメイク施術を行わせる建付けは可能か。

2\. 看護師が業務委託で施術する場合、医師の指示・監督はどの程度必要か。診察、オンライン診察、指示書、院内滞在、緊急時対応について要件を確認したい。

3\. premakeがクリニックと看護師をマッチングすることは、職業紹介、有料職業紹介、労働者派遣、募集情報等提供のいずれかに該当し得るか。許認可や表示義務は必要か。

4\. 業務委託契約であっても、クリニック側の指示が強い場合に偽装請負・実質雇用・労働者派遣と評価されるリスクはあるか。

5\. 患者からの支払いをpremakeが扱う場合、誰を役務提供者・販売者として表示すべきか。代理受領、決済代行、手数料、返金、キャンセル料の設計に問題はないか。

6\. 同意書、施術記録、写真、問診情報をpremake上で保存する場合、個人情報・医療情報・診療録等の観点から必要な契約・安全管理措置は何か。

7\. LP、看護師プロフィール、症例写真、レビュー機能、ビフォーアフター表示は医療広告規制上どこまで可能か。

8\. 事故・感染・副作用・仕上がりトラブルが発生した場合の責任分界、保険加入、損害賠償条項はどう設計すべきか。

## **5.2 分野別確認事項**

| 分野 | 確認したい内容 |
| :---- | :---- |
| 医師法・保助看法 | アートメイクの医行為該当性、看護師による診療補助としての実施条件、医師指示の内容・形式。 |
| 医療法・院内運用 | クリニックの施設内で外部看護師が施術する場合の届出・管理責任・院内規程。 |
| 労働法・職業紹介 | 業務委託、職業紹介、労働者派遣、募集情報等提供、偽装請負、労働者性。 |
| 契約法 | クリニック—看護師契約、premake利用規約、患者同意書、免責・損害賠償・解除条項。 |
| 個人情報・医療情報 | 問診、施術記録、写真、同意書、指示書、アクセス権限、委託契約、安全管理措置。 |
| 決済・消費者対応 | クレジット決済、キャンセル料、返金、特商法表示、領収書、手数料、代理受領。 |
| 医療広告 | LP、SNS、看護師紹介、口コミ、レビュー、症例写真、限定解除要件。 |

## **6.1 業務委託契約書に入れたい条項案**

* 目的・契約形態：雇用契約ではなく業務委託であること。ただし医療上必要な医師指示・院内規程遵守は別途義務とする。  
* 業務範囲：施術、事前準備、説明補助、記録、術後対応補助等を具体化。  
* 医師指示：医師指示書発行前の施術禁止、指示外施術禁止、異常時の中止・報告義務。  
* 資格・研修：看護師免許、研修履歴、技術要件、保険加入、資格停止時の通知。  
* 場所・設備：クリニック指定場所・設備の利用ルール、器具・薬剤・色素の管理責任。  
* 報酬・費用：報酬計算、支払時期、キャンセル時、返金時、消費税、インボイス、源泉徴収の確認。  
* 記録・個人情報：施術記録、写真、同意書、患者情報の取扱い、SNS掲載禁止、秘密保持。  
* 事故・苦情対応：副作用、感染、医療事故、クレーム、返金請求時の連絡・対応フロー。  
* 責任・保険：看護師の過失、クリニックの施設管理責任、医師判断、premakeシステムの責任分担。  
* 解除・停止：重大違反、資格喪失、無断キャンセル、虚偽記録、患者情報漏えい時の即時解除。

# **7\. 表現・画面設計で避けたいこと**

| 避けたい表現 | 理由 | 代替表現案 |
| :---- | :---- | :---- |
| premakeが安全なアートメイクを提供します | premakeが医療提供主体・安全保証主体に見える。 | 提携医療機関・医師・看護師による施術の予約・業務管理を支援します。 |
| premake認定看護師だから安心 | 品質保証・医療広告・責任の問題。 | 登録看護師の資格情報・対応可能範囲を確認できます。 |
| 医師不要／簡単に施術可能 | 医師法・保助看法上の誤解を招く。 | 医師の判断・指示のもと、医療機関で実施されます。 |
| 絶対に失敗しない／副作用なし | 虚偽・誇大広告、医療広告リスク。 | リスク・副作用を確認し、医師の判断を受けてください。 |
| 口コミ・症例写真を自由掲載 | 医療広告規制上の確認が必要。 | 弁護士確認後、掲載条件・同意・限定解除要件を満たす範囲で掲載。 |

# **8\. 相談で得たい回答**
