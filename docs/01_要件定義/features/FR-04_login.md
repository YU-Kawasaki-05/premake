# FR-04: ログイン

## 概要
全認証ユーザー（U-01 看護師 / U-02 施設管理者 / U-03 指示医 / U-04 運営 / U-06 法人管理者）の共通ログイン機能。メール+パスワード または Google OAuth (FR-81)。MFA 設定済みなら 2 要素目を要求 (FR-07)。

## アクター
- 全認証ユーザー（U-01〜U-04, U-06）
- ゲストユーザー（U-05）はログイン不要のため対象外

## 入力データ
| フィールド | 型 | 必須 | 制約 |
|-----------|---|------|------|
| email | string | ○ | RFC5322 形式 |
| password | string | ○ | （ハッシュ照合のため文字数制約は実行時のみ） |
| remember_me | boolean | × | true なら 30 日間ログイン保持 |

## 出力 / 結果
- **正常系**: セッション Cookie 発行、ロールに応じたダッシュボードへリダイレクト
  - U-01 → 看護師ダッシュボード
  - U-02 → 施設ダッシュボード
  - U-03 → 指示医ダッシュボード
  - U-04 → 運営管理画面
  - U-06 → 法人ダッシュボード
- **MFA 設定時**: 2FA 入力画面へ遷移（一時セッション発行）
- **異常系**: エラーメッセージ表示

## ビジネスルール
- BR-04-01: 認証失敗時のエラーメッセージは「メールアドレスまたはパスワードが正しくありません」（メールの存在有無を漏らさない）。
- BR-04-02: 連続失敗 5 回で当該アカウントを 15 分間ロック。ロック中は正しいパスワードでも失敗扱い。
- BR-04-03: 同一 IP からの 1 分間のログイン試行は 10 回まで（429）。
- BR-04-04: `users.status` が `suspended` の場合はログイン不可。「アカウントが停止されています。運営へお問い合わせください」を表示。
- BR-04-05: `email_unverified` 状態でのログインは可能だが、機能制限ありの状態（ダッシュボードに「メールアドレス未確認」バナー）。
- BR-04-06: セッショントークンは HttpOnly + Secure + SameSite=Lax の Cookie。
- BR-04-07: セッション有効期限は通常 24 時間、`remember_me=true` で 30 日間。
- BR-04-08: ログイン成功・失敗は監査ログ（FR-76）に記録（IP / UA / 時刻）。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| メール未登録 | 「メールアドレスまたはパスワードが正しくありません」 |
| パスワード誤り | 同上 |
| アカウントロック中 | 「アカウントがロックされています。15 分後に再試行してください」 |
| アカウント停止中 | 「アカウントが停止されています」 + サポート導線 |
| レート制限超過 | 429 + 待ち時間表示 |
| MFA 必要 | 2FA 入力画面へ遷移 |

## 受入基準（AC）

### AC-04-01: 正常系 — メール+パスワードログイン
```gherkin
Given email "nurse@example.com" のユーザーが status=email_verified, license_status=approved
When 正しいパスワードでログインを試みる
Then セッション Cookie が発行される
And 看護師ダッシュボードへリダイレクトされる
And 監査ログに login_success が記録される
```

### AC-04-02: 異常系 — パスワード誤り
```gherkin
When 誤ったパスワードでログイン
Then エラー「メールアドレスまたはパスワードが正しくありません」が表示される
And セッションは発行されない
And 監査ログに login_failed が記録される
```

### AC-04-03: アカウントロック
```gherkin
Given email "x@example.com" で 5 回連続ログイン失敗
When 6 回目を試みる
Then 正しいパスワードでもロック中エラーが表示される
And 15 分経過後にロックが自動解除される
```

### AC-04-04: メール未確認状態でのログイン
```gherkin
Given users.status=email_unverified のユーザー
When 正しいパスワードでログイン
Then ログインは成功する
But ダッシュボードに「メールアドレスを確認してください」バナーが表示される
And 予約申込（FR-21）等のコア機能は disabled
```

### AC-04-05: MFA 設定済みユーザー
```gherkin
Given users.mfa_enabled=true のユーザー
When 正しいパスワードでログイン
Then 2FA 入力画面に遷移する
And 一時セッション（5 分有効）が発行される
And パスワードのみではダッシュボードに到達しない
```

### AC-04-06: セッション有効期限
```gherkin
Given remember_me=false でログイン
When 24 時間 1 分が経過
And API リクエストを送信
Then 401 が返り、ログイン画面にリダイレクトされる

Given remember_me=true でログイン
When 30 日 1 時間が経過
Then 同様に 401
```

### AC-04-07: 停止アカウント
```gherkin
Given users.status=suspended のユーザー
When 正しいパスワードでログイン
Then エラー「アカウントが停止されています」が表示される
And セッションは発行されない
```

## サブ機能
- FR-04-1: パスワードログイン
- FR-04-2: アカウントロック / 自動解除
- FR-04-3: ロール別リダイレクト
