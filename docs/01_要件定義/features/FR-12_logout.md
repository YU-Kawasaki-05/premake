# FR-12: ログアウト・セッション管理

## 概要
ユーザーが自身のセッションを終了する機能。単一デバイスでのログアウト + 全デバイスからのログアウト + 他デバイスのセッション一覧表示。

## アクター
- 全認証ユーザー

## 入力データ
| フィールド | 型 | 必須 | 制約 |
|-----------|---|------|------|
| action | enum | ○ | "logout" / "logout_all_devices" / "logout_specific_session" |
| session_id | uuid | ×（specific 時必須） | - |

## 出力 / 結果
- logout: 現在の Cookie のセッション ID を破棄、Cookie をクリア、ログイン画面へリダイレクト
- logout_all_devices: 当該ユーザーの全セッション破棄（他デバイス含む）
- logout_specific_session: 指定したセッションだけ破棄

## ビジネスルール
- BR-12-01: ログアウトは即時反映。Cookie 削除 + サーバーセッション破棄。
- BR-12-02: セッション一覧画面に各セッションの IP / UA / 最終アクティビティを表示。
- BR-12-03: 監査ログ（FR-76）に logout を記録。
- BR-12-04: パスワード変更（FR-05）/ MFA 設定変更（FR-07）/ 凍結（FR-11）時は **強制全ログアウト**。
- BR-12-05: 30 日間アクティビティのないセッションは自動削除（バックエンドジョブ）。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| 既に無効なセッション | エラー無し（冪等）、ログイン画面へリダイレクト |

## 受入基準（AC）

### AC-12-01: 通常ログアウト
```gherkin
Given U-01 がログイン中
When ヘッダーメニューから「ログアウト」をクリック
Then セッション Cookie が削除される
And サーバー側でセッションが無効化される
And ログイン画面へリダイレクトされる
And 監査ログに logout が記録される
```

### AC-12-02: 全デバイスログアウト
```gherkin
Given U-01 が 3 デバイス（PC / スマホ / タブレット）でログイン中
When 設定画面で「全デバイスからログアウト」を選択
Then 3 デバイス全てのセッションが無効化
And 各デバイスの次回 API 呼び出しで 401
```

### AC-12-03: セッション一覧表示
```gherkin
Given U-01 が複数デバイスでログイン中
When 「セッション管理」画面を開く
Then アクティブなセッション一覧が表示される（IP / UA / 最終アクティビティ / 現在のセッションマーク）
When 特定セッションの「ログアウト」をクリック
Then 当該セッションのみ無効化される
```

### AC-12-04: 30 日非アクティブセッション自動削除
```gherkin
Given セッションが 30 日 1 時間アクティビティなし
When バックグラウンドジョブが走る
Then 当該セッションが自動削除される
And 当該デバイスでの API 呼び出しは 401
```
