# FR-15: スペース料金設定

## 概要
スペースの利用料金を時間単位で設定する。基本料金・時間帯別・曜日別の差分設定が可能。

## アクター
- U-02 施設管理者
- U-06 法人管理者

## 入力データ
| フィールド | 型 | 必須 | 制約 |
|-----------|---|------|------|
| 基本料金（円/時間） | int | ○ | 100〜100000 |
| 課金単位 | enum | ○ | "1 時間" / "30 分" / "15 分" |
| 最低利用時間 | int | ○ | 30〜480 分 |
| 時間帯別差分 | array | × | 例: [{時間帯: "18:00-22:00", 倍率: 1.2}] |
| 曜日別差分 | array | × | 例: [{曜日: "土日祝", 倍率: 1.3}] |
| 直前予約割引 | int (%) | × | 0〜50 |
| 連続利用割引 | int (%) | × | 0〜30 |
| 通貨 | string | ○ | "JPY" 固定 |

## 出力 / 結果
- `space_pricing` テーブルに INSERT/UPDATE
- 履歴テーブル `space_pricing_history` で過去料金を保持（既予約の料金保証用）

## ビジネスルール
- BR-15-01: 既予約は申込時の料金が固定（料金変更で既予約の請求額は変わらない）。
- BR-15-02: 料金変更は即時反映、ただし変更時刻以降の新規予約のみ。
- BR-15-03: 基本料金 = 0 は禁止（無料スペースは想定外）。
- BR-15-04: プラットフォーム手数料率はシステム側で固定（[仮決定]: 15%、Phase 2 で確定）。
- BR-15-05: 最低利用時間と課金単位の整合チェック（最低利用時間 ≥ 課金単位）。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| 基本料金が 0 以下 | 「基本料金は 1 円以上で設定してください」 |
| 倍率が異常値 | 「倍率は 0.5〜3.0 で設定してください」 |

## 受入基準（AC）

### AC-15-01: 基本料金設定
```gherkin
Given スペース S-001
When U-02 が「基本料金 5000 円/時、最低 60 分」を設定
Then space_pricing が UPDATE される
And 検索結果に表示される料金が反映される
```

### AC-15-02: 時間帯倍率
```gherkin
Given 基本料金 5000 円/時、夜間（18-22 時）倍率 1.2
When 看護師が 19:00-21:00 で予約申込
Then 計算料金 = 5000 × 1.2 × 2h = 12000 円
```

### AC-15-03: 既予約の料金保証
```gherkin
Given 看護師が 5000 円/時で予約成立済み（未施術）
When U-02 が料金を 6000 円/時に変更
Then 当該既予約の請求額は 5000 円/時のまま
And 変更後の新規予約は 6000 円/時
```

### AC-15-04: 料金履歴
```gherkin
Given 料金を 3 回変更
Then space_pricing_history に 3 件の履歴が残る
And 各履歴に effective_from, effective_to が記録される
```
