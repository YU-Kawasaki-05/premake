# FR-16: 空き枠カレンダー編集

## 概要
スペースの空き枠（看護師が予約可能な時間帯）を時刻単位で管理する。営業時間設定、繰り返しルール、個別ブロック（メンテナンス等）を扱う。

## アクター
- U-02 施設管理者
- U-06 法人管理者

## 入力データ

### 通常営業ルール（繰り返し）
| フィールド | 型 | 必須 | 制約 |
|-----------|---|------|------|
| 曜日 | enum[] | ○ | "月"〜"日" 複数選択 |
| 開始時刻 | time | ○ | 例: 09:00 |
| 終了時刻 | time | ○ | 開始時刻より後 |
| 有効期間 | date range | × | デフォルト無期限 |

### 個別ブロック（営業時間外）
| 日時範囲 | datetime range | ○ | 開始 < 終了 |
| 理由 | string | × | 1〜200 文字（メンテナンス、貸切等） |

### 個別オープン（特別開店）
| 日時範囲 | datetime range | ○ | - |
| 備考 | string | × | - |

## 出力 / 結果
- `space_availability_rules` に繰り返しルール
- `space_availability_overrides` に個別ブロック / 個別オープン
- 検索（FR-19）と予約申込（FR-21）はこの結合結果から空き枠を判定

## ビジネスルール
- BR-16-01: 既予約とぶつかるブロック設定はエラー（既予約をキャンセルしてからブロックする運用）。
- BR-16-02: タイムゾーンは Asia/Tokyo 固定（[仮決定]、海外展開時に再設計）。
- BR-16-03: 空き枠の最小単位はスペース料金の課金単位（FR-15）と整合。
- BR-16-04: iCal フィードを生成し、施設の Google Calendar 等に同期可能（任意機能、β後）。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| 既予約とぶつかる | 「{予約番号} と競合します。先に予約を処理してください」 |
| 開始 ≥ 終了 | 「終了時刻は開始時刻より後にしてください」 |

## 受入基準（AC）

### AC-16-01: 繰り返しルール
```gherkin
Given スペース S-001
When U-02 が「平日 09:00-18:00」を有効ルールに登録
Then 平日 09:00-18:00 は予約可能
And 土日は予約不可
```

### AC-16-02: 個別ブロック
```gherkin
Given 平日営業中
When U-02 が「2026-06-15 終日メンテナンス」をブロック
Then 2026-06-15 は予約不可
But 2026-06-16 は通常通り予約可能
```

### AC-16-03: 個別オープン
```gherkin
Given 土日は通常営業外
When U-02 が「2026-06-13 (土) 14:00-18:00 特別営業」を登録
Then 当該時刻のみ予約可能
```

### AC-16-04: 既予約とぶつかるブロック
```gherkin
Given 2026-06-15 13:00-15:00 に既予約あり
When U-02 が 2026-06-15 終日ブロックを試みる
Then エラー「既予約 B-XXX と競合します」
And ブロックは登録されない
```
