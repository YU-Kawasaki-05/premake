# FR-18: 施設の指示医割当

## 概要
施設管理者（U-02）または法人管理者（U-06）が、施設で稼働する指示医を登録・管理する。予約発生時にどの医師が指示書を発行するかの基準となる。

## アクター
- U-02 施設管理者
- U-06 法人管理者

## 入力データ
| フィールド | 型 | 必須 | 制約 |
|-----------|---|------|------|
| facility_id | uuid | ○ | 自施設 |
| doctor_id | uuid | ○ | 招待済み + 承認済みの U-03 |
| デフォルト指示医 | boolean | × | 1 施設 1 名のみ |
| 担当スペース（複数） | space_id[] | × | 全スペース or 個別指定 |
| 担当時間帯 | array | × | 例: 平日 9-18 時 |

## 出力 / 結果
- `doctor_facility_assignments` に INSERT（M:N）
- 自動指示医割当ロジックの基準データになる

## ビジネスルール
- BR-18-01: 1 施設には最低 1 名の指示医が割当必須（公開条件）。
- BR-18-02: 予約発生時の指示医選択ロジック:
  1. 担当スペース・担当時間帯が一致する指示医を優先
  2. 該当なければデフォルト指示医
  3. デフォルト指示医不在 → 施設管理者に手動割当依頼の通知
- BR-18-03: 指示医退任時は当該レコードをアーカイブ。既予約は別指示医に再割当（U-02 操作）。
- BR-18-04: 指示医自身が複数施設を兼任する場合、各施設で独立に割当（FR-03）。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| 未承認の医師を割当 | 「医師免許審査完了後に割当可能」 |
| デフォルト指示医を 2 名以上設定 | 「デフォルトは 1 名のみ設定可能です」 |

## 受入基準（AC）

### AC-18-01: 割当
```gherkin
Given facility F-001 と医師 D-001 (license_status=approved)
When U-02 が「D-001 をデフォルト指示医として割当」
Then doctor_facility_assignments に INSERT される
And 当該 facility の予約に D-001 が自動アサインされる
```

### AC-18-02: 担当スペース指定
```gherkin
Given 医師 D-002 が「スペース S-001 のみ担当」
When スペース S-001 で予約発生
Then D-002 が指示医候補
When スペース S-002 で予約発生
Then D-002 は候補外、デフォルト指示医にフォールバック
```

### AC-18-03: デフォルト不在で予約
```gherkin
Given 担当時間帯条件に一致する医師がおらず、デフォルト医も未設定
When 予約発生（FR-21）
Then 予約は作成されるが status=needs_doctor_assignment
And U-02 に通知メール「指示医を手動割当してください」
And 看護師ダッシュボードでも「指示医割当待ち」が表示される
```
