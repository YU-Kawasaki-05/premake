# FR-19: スペース検索

## 概要
看護師（U-01）が条件指定でスペースを検索する。地域・日時・設備・料金・評価などの複合フィルタを提供。検索インデックスは publish 時に自動更新（FR-17）。

## アクター
- U-01 看護師（license_status=approved 必須）

## 入力データ
| フィールド | 型 | 必須 | 制約 |
|-----------|---|------|------|
| 地域 | string | × | 都道府県 / 市区町村 / 駅名 / 住所自由検索 |
| 利用日時 | datetime range | × | 開始-終了 |
| 設備 | enum[] | × | 拡大鏡 / Wi-Fi / 駐車場 など (AND 条件) |
| 価格上限 (円/時) | int | × | - |
| 評価 (★) | float | × | 4.0 以上 等 |
| 並び順 | enum | × | 距離 / 価格 / 評価 / 新着 |
| ページング | int | × | 1 ページ 20 件 |

## 出力 / 結果
- 該当スペース一覧（カード表示: サムネイル / 機関名 / 距離 / 料金 / 評価 / 設備バッジ）
- 該当 0 件: 緩和条件提案
- 検索クエリは検索ログに保存（運営の需要分析用）

## ビジネスルール
- BR-19-01: 検索対象は `spaces.status=published` + `facilities.status=approved` のみ。
- BR-19-02: 利用日時指定時は空き枠（FR-16）と既予約の差分から実際に予約可能なスペースのみ表示。
- BR-19-03: 距離計算は緯度経度ベース（Haversine）。地域フィルタは住所文字列検索 + 半径検索。
- BR-19-04: 検索結果は 1 リクエスト 200ms 以内（NFR-PERF）。
- BR-19-05: 検索ログには PII を含めない（ユーザー ID は記録）。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| license_status≠approved | 403、検索画面に「審査完了後に検索可能」 |
| 検索条件不正（過去日時） | 「未来の日時を指定してください」 |

## 受入基準（AC）

### AC-19-01: 基本検索
```gherkin
Given U-01 (license_status=approved)
And published スペースが 50 件
When 「東京都 / 2026-06-15 14:00-16:00 / 拡大鏡」で検索
Then 条件に該当する published スペースが返る
And 各カードに距離・料金・評価が表示される
```

### AC-19-02: 空き枠連動
```gherkin
Given スペース S-001 が 2026-06-15 14:00-16:00 に既予約あり
When 同時刻で検索
Then S-001 は結果に含まれない
```

### AC-19-03: 並び順
```gherkin
Given 検索結果 30 件
When 「料金昇順」で並び替え
Then 価格が安い順に並ぶ
```

### AC-19-04: 0 件時の緩和提案
```gherkin
When 厳しい条件で 0 件
Then 「条件を緩和すると以下が見つかります: 設備 [拡大鏡] を外す → 12 件」が提案される
```

### AC-19-05: パフォーマンス
```gherkin
Given 全国 published スペース 1000 件
When 標準的な検索クエリ
Then 200ms 以内に応答
```
