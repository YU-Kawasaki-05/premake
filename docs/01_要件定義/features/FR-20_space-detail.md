# FR-20: スペース詳細閲覧

## 概要
看護師がスペースの詳細を閲覧する画面。写真ギャラリー・設備・料金・空き枠カレンダー・施設情報・レビューを一画面で提供。

## アクター
- U-01 看護師

## 入力データ
| space_id | uuid | ○ | URL パラメータ |

## 出力 / 結果
- スペース詳細（FR-14 のフル情報）
- 施設情報（FR-13 のサマリ）
- 写真ギャラリー
- 料金（FR-15、ユーザー入力日時で計算した見積もり）
- 空き枠カレンダー（FR-16、月単位ナビゲート）
- 担当指示医情報（FR-18、氏名・診療科のみ）
- レビュー（FR-51、最新 5 件 + 全レビューへの導線）

## ビジネスルール
- BR-20-01: published スペースのみ閲覧可。unpublished/draft は 404。
- BR-20-02: 看護師の利用日時指定があれば即時見積もり料金を表示。
- BR-20-03: ページ閲覧ログを保存（運営の需要分析用）。
- BR-20-04: 「お気に入り」機能あり（β、後付け）。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| スペース未公開 | 404 |
| スペース削除済み | 404 |

## 受入基準（AC）

### AC-20-01: 詳細表示
```gherkin
Given published スペース S-001
When U-01 が S-001 詳細ページを開く
Then 写真ギャラリー / 設備 / 料金 / 空き枠カレンダー / 施設情報 / レビューが表示される
```

### AC-20-02: 即時見積もり
```gherkin
Given U-01 が検索画面で「2026-06-15 14:00-16:00」を指定して S-001 詳細へ遷移
Then 見積もり料金「10,000 円（5000 円 × 2 時間）」が表示される
```

### AC-20-03: 空き枠カレンダー
```gherkin
Given S-001 の 6 月の空き枠
When カレンダーで「6 月」を選択
Then 空き枠（緑）/ 既予約（赤）/ ブロック（グレー）が日付ごとに表示
And クリックで時刻別の詳細表示
```

### AC-20-04: レビュー連動
```gherkin
Given S-001 にレビュー 12 件
When 詳細ページを開く
Then 平均評価 ★4.6 / 12 件 が表示
And 最新 5 件のレビューが表示
And 「全レビューを見る」リンク
```

## サブ機能

- FR-20-2: 即時見積もり
- FR-20-3: 空き枠カレンダー
- FR-20-4: お気に入り（β後）
