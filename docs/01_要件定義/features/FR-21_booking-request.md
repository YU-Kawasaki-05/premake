# FR-21: 予約申込

## 概要
看護師（U-01）がスペース詳細から予約を申し込む。承認制（FR-22）と即時確定の選択肢があるが β段階は **承認制のみ**（[仮決定]）。予約には FR-88 のセッション列（カウンセリング+施術）を必ず 1 つ以上含む。

## アクター
- U-01 看護師（license_status=approved 必須）

## 入力データ
| フィールド | 型 | 必須 | 制約 |
|-----------|---|------|------|
| space_id | uuid | ○ | published |
| sessions | array | ○ | 1〜N 個。各 {type: "consultation"/"treatment", start_at, end_at} |
| 利用目的（自由記述） | string | × | 1〜500 文字 |
| 想定施術メニュー | enum[] | ○ | "眉" / "リップ" / "アイライン" / "その他" |
| 利用客情報（任意で事前入力） | array | × | カウンセリング/施術時の利用客リンク先 |
| 看護師カード登録済み | boolean | ○ | 未登録ならカード登録 (FR-36) を促す |

## 出力 / 結果
- `bookings` レコード作成（status=pending_approval）
- `booking_sessions` に各セッション INSERT（FR-88）
- 施設管理者 (U-02) に通知メール（FR-46）
- 看護師ダッシュボード (FR-65) に「承認待ち」表示
- 指示医（FR-18 で自動アサイン）に通知 (FR-28)

## ビジネスルール
- BR-21-01: license_status=approved 必須。未承認時は 403。
- BR-21-02: カード登録 (FR-36) 必須。未登録時はカード登録モーダル → 申込フローに復帰。
- BR-21-03: セッションの時間がスペースの空き枠 (FR-16) と重ならないと申込不可。
- BR-21-04: 同時刻に同看護師の他予約があればエラー（ダブルブッキング防止）。
- BR-21-05: 申込時点で料金計算 (FR-15) し `bookings.amount_estimate` に固定。
- BR-21-06: 申込から承認待ちは **48 時間**（FR-22 の SLA）。経過後は自動キャンセル。
- BR-21-07: 異常な申込パターン（短時間に大量、同一看護師の連続キャンセル等）は自動的に運営アラート。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| 空き枠と衝突 | 「指定時刻は予約済みです」 |
| 自分の他予約と衝突 | 「同時刻に別予約があります」 |
| カード未登録 | カード登録ダイアログへ |

## 受入基準（AC）

### AC-21-01: 正常系
```gherkin
Given U-01 (license_status=approved, card_registered=true)
And スペース S-001 の 2026-06-15 14:00-16:00 が空き
When U-01 が「カウンセリング 14:00-14:30 + 施術 14:30-16:00」で申込
And 想定メニュー「眉」を選択
Then bookings レコード（status=pending_approval, amount_estimate=10000）作成
And booking_sessions に 2 件 INSERT
And 施設 U-02 と指示医 U-03 に通知メール
And 看護師ダッシュボードに「承認待ち」表示
```

### AC-21-02: 空き枠衝突
```gherkin
Given S-001 の 14:00-16:00 に既予約あり
When 同時刻で申込
Then エラー「指定時刻は予約済みです」
And bookings レコードは作成されない
```

### AC-21-03: カード未登録
```gherkin
Given U-01 のカード未登録
When 申込ボタンクリック
Then カード登録モーダルが表示される
When カード登録完了
Then 申込フローに復帰し、再度確認画面へ
```

### AC-21-04: 48 時間自動キャンセル
```gherkin
Given pending_approval の予約が 48 時間 1 分経過
Then バックグラウンドジョブ（FR-77）で自動 cancelled に遷移
And 看護師に「承認期限切れによる自動キャンセル」通知メール
```

### AC-21-05: 自分の他予約との衝突
```gherkin
Given U-01 が 2026-06-15 14:00-15:00 に別の予約 B-002 を持つ
When 同看護師が 2026-06-15 14:30-15:30 で別スペース申込
Then エラー「同時刻に別予約があります（B-002）」
```

## サブ機能
- FR-21-1: 申込フォーム
- FR-21-2: 衝突チェック
- FR-21-3: 自動キャンセル（48h）
