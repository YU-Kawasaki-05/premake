# FR-27: 予約詳細

## 概要
予約の全情報を 1 画面で閲覧。関係者ごとに表示される情報は権限により異なる。タイムラインで予約のライフサイクル（申込→承認→指示書発行→施術→完了→決済）を可視化。

## アクター
- U-01 看護師（自分の予約）
- U-02 施設管理者（自施設）
- U-03 指示医（自施設）
- U-04 運営（全予約）
- U-06 法人管理者（配下施設）

## 入力データ
| booking_id | uuid | ○ | URL パラメータ |

## 出力 / 結果
- 予約基本情報（FR-21 入力）
- セッション一覧（FR-88、各セッションの状態）
- 担当者（看護師 / 施設 / 指示医）
- 利用客情報（K カテゴリ紐付き時、権限内で）
- 指示書ステータス（FR-29、未発行 / 発行済 / 確認済）
- 決済ステータス（FR-43、オーソリ済 / キャプチャ済 / 返金済）
- タイムライン（イベント履歴）
- 利用可能アクション（変更・キャンセル・施術記録投入・指示書発行・決済確認 等、権限とステータスで動的）

## ビジネスルール
- BR-27-01: 利用客の個人情報（氏名・電話番号）は権限により部分マスキング:
  - U-01 看護師（担当）: フル表示
  - U-02 施設管理者: 名前イニシャル + 電話下 4 桁
  - U-03 指示医: フル表示
  - U-04 運営: 監査目的のみ、閲覧時は監査ログ記録
- BR-27-02: タイムラインのイベントは監査ログ（FR-76）と連動。
- BR-27-03: アクションボタンはユーザー権限・予約ステータス・SLA で動的に出し分け。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| 権限外の予約 | 404（IDが分からない振る舞い） |

## 受入基準（AC）

### AC-27-01: 看護師視点
```gherkin
Given U-01 が approved 予約 B-001 の担当
When 予約詳細を開く
Then 全情報（看護師目線）が表示
And アクション「変更」「キャンセル」が表示
```

### AC-27-02: 指示医視点（指示書未発行）
```gherkin
Given U-03 が B-001 の指示医
And 指示書未発行
When 予約詳細を開く
Then 「指示書発行」ボタンが目立つ位置に表示
```

### AC-27-03: 個人情報マスキング
```gherkin
Given B-001 に利用客「山田 太郎、090-1234-5678」紐付け
When U-02 施設管理者が詳細を開く
Then 「山田 T、090-XXXX-5678」と表示
When U-01 担当看護師が詳細を開く
Then 「山田 太郎、090-1234-5678」とフル表示
```

### AC-27-04: タイムライン
```gherkin
Given B-001 が 申込→承認→指示書発行 の状態
When 詳細を開く
Then タイムラインに 3 イベント（時刻・実行者）が表示
```

### AC-27-05: 権限外アクセス
```gherkin
Given B-001 は F-001 の予約
When U-02 (F-002 所属) が B-001 詳細にアクセス
Then 404 が返る
```
