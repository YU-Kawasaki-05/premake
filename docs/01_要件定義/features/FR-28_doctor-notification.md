# FR-28: 予約発生時の指示医通知

## 概要
予約が承認 (FR-22) されたら自動アサイン (FR-18) されている指示医 (U-03) に通知し、電子指示書発行 (FR-29) を促す。施術開始時刻の 24h / 1h 前にもリマインド。

## アクター
- U-03 指示医（受信側）

## トリガー
- bookings.status: pending_approval → approved（FR-22）
- 施術開始 24 時間前
- 施術開始 1 時間前
- 指示書未発行で施術開始 30 分前 → エスカレーション

## 出力 / 結果
- メール通知（FR-46）
- SMS 通知（重要度高、設定で有効化）
- アプリ内通知（指示医ダッシュボード FR-67）
- エスカレーション: 30 分前未発行で施設管理者・運営にも通知

## ビジネスルール
- BR-28-01: 通知は冪等（重複送信防止）。job_id で管理。
- BR-28-02: 指示医がオフライン（電子指示書未発行）な場合、施設管理者にエスカレーション + 代替指示医検討。
- BR-28-03: 通知設定（FR-48）でオプトアウト可能。ただし「施術 1h 前」の高優先度通知は強制（オプトアウト不可）。
- BR-28-04: 通知履歴を `notifications` テーブルに保持（送信時刻 / 配信状態 / 既読状態）。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| メール送信失敗 | リトライ（指数バックオフ、3 回まで） |
| SMS 送信失敗 | 同上 |
| 指示医不在（30 分前未発行） | 施設・運営エスカレーション |

## 受入基準（AC）

### AC-28-01: 承認時の即時通知
```gherkin
Given 予約 B-001 が approved になった
And 指示医 D-001 が自動アサイン
Then D-001 にメール通知が送信
And アプリ内通知が表示される
And ダッシュボードのバッジカウントが +1
```

### AC-28-02: 24h 前リマインド
```gherkin
Given 予約 B-001 の施術開始 24h 前
And 指示書未発行
Then D-001 に「24h 前リマインド」メール送信
```

### AC-28-03: 1h 前高優先度
```gherkin
Given 予約 B-001 の施術開始 1h 前
And 指示書未発行
Then D-001 にメール + SMS 送信
And SMS は通知設定に関わらず送信
```

### AC-28-04: 30 分前エスカレーション
```gherkin
Given 予約 B-001 の施術開始 30 分前
And 指示書未発行
Then 施設管理者 U-02 と運営 U-04 に通知
And 「指示医不在の可能性、要確認」アラート
```

### AC-28-05: 通知冪等性
```gherkin
Given 予約 B-001 が一度 approved → rejected → approved に戻る
Then 「approved 即時通知」は冪等であり、同一 job_id で重複送信しない
```

## サブ機能
- FR-28-1: 即時通知
- FR-28-2: リマインド (24h, 1h)
- FR-28-3: エスカレーション
