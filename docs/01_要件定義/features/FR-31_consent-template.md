# FR-31: 同意書テンプレート編集

## 概要
施設または看護師が利用客向けの同意書テンプレートを編集する。プラットフォーム標準テンプレートを基礎に、施設・看護師ごとにカスタマイズ可能。

## アクター
- U-02 施設管理者（施設デフォルトテンプレート）
- U-01 看護師（自分用テンプレート、施設デフォルトを基礎に変更）

## 入力データ
| フィールド | 型 | 必須 | 制約 |
|-----------|---|------|------|
| owner_type | enum | ○ | "platform" / "facility" / "nurse" |
| owner_id | uuid | × | facility_id / nurse_id |
| title | string | ○ | 1〜200 文字 |
| sections | array | ○ | { heading, body, required_acknowledgement } の配列 |
| version | int | ○ | 自動採番、編集ごとに増分 |

## 出力 / 結果
- `consent_templates` テーブルに INSERT / UPDATE
- 利用客の同意書記入（FR-32）時にこのテンプレートが使われる
- バージョン管理: 古いバージョンの記入済み同意書はそのまま保持

## ビジネスルール
- BR-31-01: プラットフォーム標準テンプレート（owner_type=platform）はベースとして常に存在し、運営のみ編集可。
- BR-31-02: 施設テンプレートは標準を基礎にした diff として保存（標準改訂時に通知）。
- BR-31-03: 看護師テンプレートは施設テンプレート（or 標準）を基礎にする。
- BR-31-04: テンプレート変更は新バージョンとして保存、過去記入済み同意書はそのバージョンに紐付く。
- BR-31-05: 法令的に必須の項目（「医療行為であること」「副作用」「医師指示の存在」「個人情報の取扱」）は標準テンプレートに含まれ、削除不可。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| 必須項目を削除しようとする | 「この項目は法令上必須のため削除できません」 |

## 受入基準（AC）

### AC-31-01: 標準テンプレート閲覧
```gherkin
Given U-02 がテンプレート編集画面を開く
Then プラットフォーム標準テンプレート（読み取り専用）+ 自施設テンプレートが並んで表示される
```

### AC-31-02: 施設テンプレート作成
```gherkin
Given U-02 が標準テンプレートを基礎に編集
When 「保存」をクリック
Then consent_templates (owner=facility, version=1) が作成
And 新規予約からこのテンプレートが使われる
```

### AC-31-03: 看護師テンプレート（施設テンプレートを基礎）
```gherkin
Given U-01 が「テンプレート編集」を開く
And 自施設のデフォルトが存在
Then 施設テンプレートを基礎にした編集画面が表示
When U-01 が編集 + 保存
Then 自分用テンプレート（owner=nurse, version=1）作成
```

### AC-31-04: 必須項目削除不可
```gherkin
Given U-02 が「医師指示の存在」セクションを削除しようとする
Then 削除ボタンが disabled
And ツールチップで「この項目は法令上必須」が表示
```

### AC-31-05: バージョン管理
```gherkin
Given facility テンプレート v1 で記入済み同意書 5 件
When v2 に編集
Then v2 が現行になり、新規記入は v2 を使う
But 5 件の記入済み同意書は v1 として保持される
```
