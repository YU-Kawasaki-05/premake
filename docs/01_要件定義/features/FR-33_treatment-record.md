# FR-33: 施術記録投入

## 概要
看護師（U-01）が施術完了後、施術記録（実施内容・施術前後写真・薬剤・所見等）を入力する。指示医（FR-34）の確認を経て医療記録として確定。

## アクター
- U-01 看護師（自分が担当した施術）

## 入力データ
| フィールド | 型 | 必須 | 制約 |
|-----------|---|------|------|
| booking_session_id | uuid | ○ | 自分担当の施術セッション |
| 施術部位 | enum[] | ○ | 「眉」「リップ」「アイライン」など。指示書と整合 |
| 使用色素 | array | ○ | 製品名 / 色番号 / ロット番号 |
| 麻酔の使用 | object | × | 種別 / 量 |
| 施術前写真 | file[] | ○ | 部位ごと最低 1 枚、計 1〜10 枚 |
| 施術後写真 | file[] | ○ | 同上 |
| 所見 | string | × | 1〜2000 文字 |
| 開始時刻 / 終了時刻 | datetime | ○ | - |
| 利用客の主観評価 | int | × | 1〜5 |
| 異変・特記事項 | string | × | 異変があれば必須 |

## 出力 / 結果
- `treatment_records` レコード作成（status=submitted）
- 写真は別 bucket（暗号化）保存
- 指示医（FR-34）に確認依頼通知
- 該当 booking_session.status=completed に更新

## ビジネスルール
- BR-33-01: 投入は施術担当看護師のみ。
- BR-33-02: 投入は施術終了後 24 時間以内推奨（48h 以降は警告 + 運営アラート）。
- BR-33-03: 施術部位は指示書（FR-29）の内容と整合（不一致時は「指示書外の施術」として目立つ警告 + 異変記入必須）。
- BR-33-04: 写真は **個人特定情報を伴うため暗号化保存** + 閲覧時署名付き URL（FR-78）。
- BR-33-05: 投入後の編集は指示医確認前のみ可能（編集履歴を残す）。指示医確認後は「修正記録（追記）」フロー。
- BR-33-06: 7 年保存（医療記録保存義務）。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| 自分担当でない施術 | 403 |
| 必須欠落 | フィールドエラー |
| 指示書部位と施術部位の乖離 | 警告ダイアログ + 異変記入必須 |

## 受入基準（AC）

### AC-33-01: 正常系
```gherkin
Given U-01 が自分担当の施術セッション S-2 を完了
When 必須項目（施術部位 / 色素 / 写真 / 時刻）を入力
And 「投入」をクリック
Then treatment_records レコード作成
And booking_session.status=completed
And 指示医 U-03 に確認依頼通知
```

### AC-33-02: 指示書との整合チェック
```gherkin
Given 指示書は「眉」のみ
When 看護師が施術部位「眉 + リップ」を選択
Then 警告「指示書にない部位が含まれます」
And 異変・特記事項の記入必須
```

### AC-33-03: 写真暗号化
```gherkin
Given 施術記録に写真 5 枚アップロード
When ストレージ確認
Then 全写真が暗号化済み
And 閲覧時の署名付き URL が 5 分有効
```

### AC-33-04: 編集制約
```gherkin
Given 施術記録 submitted（指示医未確認）
When 看護師が編集
Then 編集可能、編集履歴に記録
Given 施術記録 confirmed（指示医確認済）
When 看護師が編集を試みる
Then エラー「修正記録の追記フローを使ってください」
```

### AC-33-05: 24h 超のアラート
```gherkin
Given 施術終了から 49h 経過、記録未投入
Then 看護師にリマインドメール
And 48h 経過時点で運営アラート（FR-56）
```
