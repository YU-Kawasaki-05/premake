# FR-35: 施術記録の検索・閲覧

## 概要
権限内ユーザーが施術記録を検索・閲覧する。閲覧アクセスは全て監査ログ（FR-76）に記録、PII マスキング（FR-78）適用。

## アクター
- U-01 看護師（自分が施術）
- U-02 施設管理者（自施設）
- U-03 指示医（自施設）
- U-04 運営（監査）
- U-06 法人管理者（配下施設、監査用）

## 入力データ
| date_range | date range | × | - |
| nurse_id / doctor_id / facility_id | uuid | × | - |
| status | enum[] | × | submitted / confirmed / revision_requested |
| keyword | string | × | 利用客名イニシャル / 部位 |

## 出力 / 結果
- 該当記録一覧
- 詳細表示（写真・メタ・タイムライン）

## ビジネスルール
- BR-35-01: 自分が関わった記録のみ表示（U-01: 担当した施術 / U-02: 自施設 / U-03: 自施設）。
- BR-35-02: U-04 運営は全件閲覧可、ただし監査ログ強制記録 + 閲覧理由必須入力。
- BR-35-03: U-06 は配下施設の記録を「監査用」として閲覧可、ただし PII マスキング強化（氏名イニシャル / 写真ぼかし）。
- BR-35-04: 写真は署名付き URL（5 分）配信、閲覧ごとに監査ログ。
- BR-35-05: ダウンロード機能は U-04 / U-02（理由付き）のみ可。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| 権限外の記録 | 404 |

## 受入基準（AC）

### AC-35-01: 看護師の自分記録一覧
```gherkin
Given U-01 が 50 件の施術記録持つ
When 検索画面を開く
Then 自分が施術した記録のみ表示
And 写真は通常表示（ぼかしなし）
```

### AC-35-02: 法人管理者の配下記録閲覧（監査）
```gherkin
Given U-06 が配下 F-001 の記録を閲覧
Then 利用客名がイニシャル表示
And 写真はぼかし
And 閲覧が監査ログに「U-06 (id) 監査閲覧」として記録
```

### AC-35-03: 運営の閲覧（理由必須）
```gherkin
Given U-04 が記録 R-001 を閲覧
Then 閲覧理由入力ダイアログが表示
When 「不正報告対応」と入力
Then 監査ログに理由付きで記録
And 記録閲覧画面に遷移
```

### AC-35-04: ダウンロード制限
```gherkin
Given U-03 指示医が記録閲覧画面
When 「PDF ダウンロード」をクリック
Then 「ダウンロード権限がありません」エラー（U-04 / U-02 のみ可）
```
