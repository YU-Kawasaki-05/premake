# FR-41: キャンセルポリシー（共通）

## 概要
プラットフォーム共通のキャンセルポリシー。施設別上書き（FR-86）が無い限り、これが適用される。看護師都合・施設都合・運営強制で異なる。

## ポリシー（共通デフォルト）

### 看護師都合キャンセル
| キャンセル時期 | 返金率 | 看護師負担 |
|---|---|---|
| 7 日前以前 | 100% | 0 |
| 3〜7 日前 | 50% | 50% |
| 1〜3 日前 | 30% | 70% |
| 24 時間以内 | 0% | 100% |

### 施設都合キャンセル
- 常に **返金 100%** + 看護師補償（[仮決定]: 次回利用クーポン or 5000 円相当）

### 運営強制キャンセル
- 個別判断（不正検知 / システム障害 / 法令違反）

## ビジネスルール
- BR-41-01: 「キャンセル時期」の起点は最初のセッションの開始日時。
- BR-41-02: 利用客事前決済 (FR-39) も同ポリシー。返金は看護師の取り分から控除。
- BR-41-03: 施設都合キャンセル時の補償原資はプラットフォーム手数料 + 施設からのペナルティ（[仮決定]、Phase 2 で確定）。
- BR-41-04: ポリシー変更は告知期間 30 日以上をおく。既予約には適用前のポリシーを保証。
- BR-41-05: 施設別上書き（FR-86）がある場合はそちらを優先。

## 受入基準（AC）

### AC-41-01: 看護師都合 7 日前以前
```gherkin
Given 看護師の予約、施術まで 8 日
When キャンセル
Then 返金 100%
```

### AC-41-02: 看護師都合 1〜3 日前
```gherkin
Given 施術まで 2 日
When キャンセル
Then 返金 30%、看護師負担 70%
```

### AC-41-03: 施設都合キャンセル
```gherkin
When 施設管理者がキャンセル
Then 返金 100% + 看護師補償（クーポン）
```

### AC-41-04: 既予約のポリシー保証
```gherkin
Given 予約 B-001 が承認済み
When プラットフォームがポリシー改定
Then B-001 は旧ポリシーで処理される
And 30 日後の新規予約から新ポリシー適用
```

### AC-41-05: 施設別上書き優先
```gherkin
Given facility F-001 が「施術 2 週間前以前で 100% 返金」を上書き設定（FR-86）
When 看護師が 10 日前にキャンセル
Then F-001 のポリシーに従い返金 100%（共通ポリシーの 50% より優先）
```
