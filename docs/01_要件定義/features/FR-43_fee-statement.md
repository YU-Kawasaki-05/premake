# FR-43: 手数料明細表示

## 概要
看護師・施設・法人が決済明細・プラットフォーム手数料・送金内訳を確認する。月次集計と取引別明細の両ビューを提供。

## アクター
- U-01 看護師（自分の決済履歴）
- U-02 施設管理者（自施設の決済履歴）
- U-06 法人管理者（配下施設の集計）

## 入力データ
- date_range
- group_by (month / week / day)

## 出力 / 結果
- 集計テーブル（月次 GMV / 手数料 / 純額）
- 取引別明細（予約番号 / 日時 / 総額 / 手数料 / 送金額 / ステータス）
- CSV エクスポート（FR-58 と連動）

## ビジネスルール
- BR-43-01: 自分関連のみ表示（看護師: 自分、施設: 自施設、法人: 配下集計）。
- BR-43-02: 月次明細は前月分が翌月 5 日に確定。それ以前は速報値 + 「速報」バッジ。
- BR-43-03: ダウンロード（CSV / PDF 明細）は権限内ユーザーが自由に取得可。
- BR-43-04: 消費税表記は内税。プラットフォーム手数料の課税扱いは Phase 2 で確定。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| 該当データ 0 | ガイダンス表示 |

## 受入基準（AC）

### AC-43-01: 看護師の月次明細
```gherkin
Given U-01 が 2026 年 4 月に 10 件の予約完了
When 4 月明細を表示
Then 集計（GMV 100000 / 手数料 15000 / 純額 85000）と取引別 10 件が表示
```

### AC-43-02: 施設の月次明細
```gherkin
Given F-001 が 4 月に 30 件の予約稼働
When 4 月明細
Then 施設目線での集計（受取 GMV / 受取手数料控除後）
```

### AC-43-03: 法人横断
```gherkin
Given 法人配下 3 施設
When U-06 が 4 月明細
Then 3 施設集計 + 施設別内訳が表示
```

### AC-43-04: CSV エクスポート
```gherkin
When ユーザーが「CSV ダウンロード」
Then 当該明細の CSV ファイルがダウンロードされる
And ファイル名に期間とユーザー ID が含まれる
```

### AC-43-05: 速報値と確定値
```gherkin
Given 当月分の明細を表示
Then 「速報」バッジが付く
When 翌月 5 日経過
Then 確定値に切り替わり、バッジが外れる
```
