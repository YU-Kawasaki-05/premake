# FR-45: 看護師⇄施設のチャット（β）

## 概要
予約に紐づく看護師と施設管理者の 1:1 チャット。β表記だが本実装。テスト範囲はスモークテストのみ（DEC-09）。

## アクター
- U-01 看護師
- U-02 施設管理者

## 入力データ
| フィールド | 型 | 必須 | 制約 |
|-----------|---|------|------|
| thread_id | uuid | ○ | 予約と 1:1 紐付け |
| body | string | ○ | 1〜2000 文字 |
| attachments | file[] | × | 最大 3 枚、各 5MB |

## 出力 / 結果
- `chat_messages` レコード作成
- 相手側に通知（FR-46 メール + アプリ内）
- リアルタイム配信（Server-Sent Events または WebSocket）

## ビジネスルール
- BR-45-01: チャットスレッドは予約 (booking_id) と 1:1 紐付け。予約発生で自動作成。
- BR-45-02: 個人情報マスキング: 利用客の個人情報を含むメッセージは送信時に警告（任意で確認）。
- BR-45-03: メッセージは編集不可、削除はソフトデリート（運営は監査ログで閲覧可）。
- BR-45-04: 添付画像は **暗号化保存** + 7 日 TTL の署名付き URL。
- BR-45-05: 既読ステータス管理。
- BR-45-06: 不適切ワード自動フィルタ（軽量、運営アラート）。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| 該当予約がキャンセル済 | 送信不可、過去メッセージは閲覧可 |
| 添付サイズ超過 | 「ファイルが大きすぎます」 |

## 受入基準（AC）

### AC-45-01: メッセージ送受信
```gherkin
Given 予約 B-001 のチャットスレッド
When U-01 が「明日 14 時に到着予定です」送信
Then chat_messages レコード作成
And U-02 にアプリ内通知 + メール（即時 or バッチ）
And U-02 のチャット画面にリアルタイム表示
```

### AC-45-02: 添付ファイル
```gherkin
When U-01 が画像 1 枚（3MB）を添付して送信
Then 暗号化保存
And U-02 が表示時、署名付き URL（7 日有効）でアクセス
```

### AC-45-03: 既読
```gherkin
Given U-01 のメッセージが unread
When U-02 がチャット画面を開く
Then read_at がセットされる
And U-01 側に「既読」が表示される
```

### AC-45-04: キャンセル済予約
```gherkin
Given 予約 B-001 が cancelled
When U-01 がメッセージ送信を試みる
Then 「キャンセル済予約のためメッセージを送信できません」
And 過去メッセージは閲覧可能
```

### AC-45-05: 個人情報警告
```gherkin
Given メッセージ本文に電話番号らしき数字列を含む
When 送信ボタンクリック
Then 警告ダイアログ「電話番号を含む可能性があります。送信してよろしいですか？」
```

## サブ機能
- FR-45-1: チャット送受信
- FR-45-2: 添付・署名付き URL
- FR-45-3: 既読管理
- FR-45-4: 個人情報警告
