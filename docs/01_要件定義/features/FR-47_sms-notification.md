# FR-47: SMS 通知

## 概要
高優先度のイベントを SMS で送信。利用客向けが主用途（メール開封率が低いため）、認証ユーザーには予約直前リマインドや MFA で使用。

## アクター
- システム

## 送信対象イベント
| イベント | 受信者 | 用途 |
|---|---|---|
| 利用客の予約確認 (FR-73) | 利用客 | 確認 |
| 利用客の施術前日リマインド | 利用客 | リマインド |
| 利用客の予約照会コード (FR-74) | 利用客 | 認証 |
| MFA SMS コード (FR-07) | 認証ユーザー | 認証 |
| 指示書発行 1h 前未完了 (FR-28) | 指示医 | 緊急 |
| アカウント凍結 (FR-11) | 当該ユーザー | 重要 |

## ビジネスルール
- BR-47-01: SMS は外部 SMS プロバイダ経由（Phase 3 で選定: Twilio / AWS SNS / 国内サービス）。
- BR-47-02: 国内番号（+81）のみ対応（β段階）。海外は P2。
- BR-47-03: 1 回の送信は 70 文字以内。長文は分割可（コスト増）。
- BR-47-04: コスト管理: 1 ユーザー 1 日あたり最大 5 通（spam 防止）。
- BR-47-05: 利用客側は SMS 受信拒否設定可能（メールにフォールバック）。
- BR-47-06: 配信失敗（番号不正）時は notifications テーブルに記録、運営に通知。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| 番号不正 | 「電話番号の形式が正しくありません」 |
| 配信失敗 | リトライ後、メールにフォールバック |
| 1 日上限超過 | 送信せず、通知頻度の警告ログ |

## 受入基準（AC）

### AC-47-01: 利用客予約確認 SMS
```gherkin
Given 利用客が予約完了 (FR-70)
Then 即時 SMS「予約が確定しました。詳細: {URL}」が届く
And メールも併送
```

### AC-47-02: 配信失敗フォールバック
```gherkin
Given SMS 配信失敗（携帯電話番号エラー）
Then メールにフォールバック
And 利用客に「電話番号をご確認ください」表示
```

### AC-47-03: 上限超過
```gherkin
Given 同利用客に当日 5 通送信済み
When 6 通目を送信
Then 送信されず、メール / アプリ内通知のみ
And 監査ログに「SMS 上限到達」記録
```

### AC-47-04: 受信拒否設定
```gherkin
Given 利用客が SMS 拒否設定（前回受信時のリンクから設定）
Then SMS は送信されず、メールのみ
```
