# FR-48: 通知設定

## 概要
ユーザーがイベントごと・通知チャネル（メール / SMS / アプリ内）ごとにオン/オフを切り替える。

## アクター
- 全認証ユーザー

## 入力データ
- イベント × チャネル × オン/オフ のマトリクス
- 「すべてオフ」ボタン
- 「デフォルトに戻す」

## 出力 / 結果
- `notification_preferences` レコード更新
- FR-46 / FR-47 が送信時に参照

## ビジネスルール
- BR-48-01: 高優先度イベント（決済 / キャンセル / 凍結 / セキュリティ）は **オプトアウト不可**。
- BR-48-02: チャネル別細粒度（例: 予約承認はメールのみ、リマインドはアプリ内のみ）。
- BR-48-03: 利用客（ゲスト）の SMS 受信拒否は SMS 内のリンクから設定可能（個別予約単位）。
- BR-48-04: 設定変更は即時反映。

## 受入基準（AC）

### AC-48-01: 設定変更
```gherkin
Given U-01 が「予約承認」のメール通知をオフ
When 予約 B-001 が approved
Then メールは送信されない
And アプリ内通知は表示される（オフにしていない場合）
```

### AC-48-02: 高優先度の強制
```gherkin
Given U-01 が決済通知をオフ設定を試みる
Then UI 上「この通知はオフにできません」+ チェックボックス disabled
```

### AC-48-03: 「すべてオフ」
```gherkin
When 「すべてオフ」をクリック
Then 高優先度以外がすべて off
And 確認ダイアログ「重要な通知のみ受信します」
```

## サブ機能
- FR-48-1: イベント × チャネル設定
- FR-48-2: デフォルトリセット
- FR-48-3: 強制送信イベントの保護
