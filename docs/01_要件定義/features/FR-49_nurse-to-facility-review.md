# FR-49: 看護師→施設レビュー（β）

## 概要
施術完了後、看護師が施設・スペースを 5 段階評価 + コメント。β表記。

## アクター
- U-01 看護師

## 入力データ
| フィールド | 型 | 必須 | 制約 |
|-----------|---|------|------|
| booking_id | uuid | ○ | 自分の completed 予約 |
| star_rating | int | ○ | 1〜5 |
| カテゴリ別評価 | object | × | { 清潔さ, 設備, アクセス, スタッフ対応 } 各 1〜5 |
| コメント | string | × | 1〜1000 文字 |
| 公開設定 | enum | ○ | "public" / "facility_only" / "private" |

## 出力 / 結果
- `reviews` レコード作成
- 施設のスペース評価平均（FR-20 で表示）に反映

## ビジネスルール
- BR-49-01: 完了予約のみレビュー可能（status=completed）。
- BR-49-02: 1 予約 1 レビュー。編集は提出後 7 日以内のみ可。
- BR-49-03: コメントは不適切ワードフィルタ通過必須。引っかかったら投稿前確認 → 運営審査。
- BR-49-04: 個人特定情報を含むコメントは警告（自動検出）。
- BR-49-05: 「private」は看護師のメモ用、第三者公開なし。
- BR-49-06: 施設都合キャンセル予約はレビュー不可（β段階、Phase 2 再検討）。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| 未完了予約 | 「施術完了後にレビュー可能」 |
| 編集期限切れ | 「編集期限を過ぎています」 |

## 受入基準（AC）

### AC-49-01: 投稿
```gherkin
Given completed 予約 B-001
When U-01 が ★4 + コメント「設備が綺麗で快適でした」 + 公開
Then reviews レコード作成
And 施設の平均評価が再計算される
```

### AC-49-02: 編集期限
```gherkin
Given 投稿から 8 日経過
When U-01 が編集を試みる
Then 編集 disabled、「編集期限を過ぎています」表示
```

### AC-49-03: 不適切ワード
```gherkin
Given コメントに不適切ワード
When 投稿
Then 確認ダイアログ「内容を見直してください」
And ユーザーが押し切れば運営審査キューへ
```

### AC-49-04: 公開設定 private
```gherkin
Given U-01 が「private」で投稿
Then 当該レビューは U-01 のみ閲覧可
And 施設には表示されない
```

## サブ機能
- FR-49-1: レビュー投稿
- FR-49-2: 編集（7 日以内）
- FR-49-3: 不適切ワードフィルタ
