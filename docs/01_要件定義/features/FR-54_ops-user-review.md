# FR-54: 運営: ユーザー審査

## 概要
看護師免許 (FR-08) / 医療機関開設届 (FR-09) / 医師免許 (FR-10) / 法人 (FR-82) の各申請を一元管理・審査するインターフェース。代理オンボーディング (FR-87) の起点でもある。

## アクター
- U-04 運営

## 入力データ
- 審査キュー（pending_review 一覧）
- 各申請の詳細閲覧
- 承認 / 却下 / 追加情報依頼の判断

## 出力 / 結果
- 各申請の status 更新
- 当該ユーザーへの通知メール
- 監査ログ記録

## ビジネスルール
- BR-54-01: 審査キューは「申請日昇順」をデフォルト。SLA 接近は警告色。
- BR-54-02: 各申請は他運営の審査中状態をロックして二重審査を防ぐ。
- BR-54-03: 却下・追加情報依頼は理由必須。テンプレート定型文 + 自由記述。
- BR-54-04: 審査 SLA: 看護師 / 医師 = 3 営業日、施設 / 法人 = 5 営業日（[仮決定]）。
- BR-54-05: 不正検知補助: 同一画像が他申請と類似（pHash）等を自動検知してアラート。

## 受入基準（AC）

### AC-54-01: 審査キュー表示
```gherkin
Given pending_review が 30 件
When U-04 が審査画面を開く
Then 30 件が申請日昇順
And SLA 接近（残 1 営業日）は警告色
```

### AC-54-02: 二重審査防止
```gherkin
Given 申請 A-001 を運営 X が開いている
When 運営 Y が同申請を開く
Then 「他の運営が審査中です」バナー
And 編集不可（読み取りのみ）
```

### AC-54-03: 不正検知
```gherkin
Given 看護師免許画像が他申請と pHash 類似
When 運営が当該申請を開く
Then 「類似画像検出」アラート + 比較画面
```

### AC-54-04: テンプレート定型文
```gherkin
When 「却下」+ テンプレート「画像不鮮明」選択
Then 定型文がコメント欄に挿入
And 必要に応じて編集して送信
```

## サブ機能
- FR-54-1: 統合審査キュー
- FR-54-2: 二重審査ロック
- FR-54-3: 不正検知補助
- FR-54-4: 定型文テンプレート
