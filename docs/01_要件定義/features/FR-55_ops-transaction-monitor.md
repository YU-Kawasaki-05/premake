# FR-55: 運営: 取引監視

## 概要
全予約・決済・返金の状態をリアルタイムに監視。異常検知 + ダッシュボード + 個別詳細閲覧。

## アクター
- U-04 運営

## 入力データ
- フィルタ: ステータス / 期間 / 施設 / 看護師 / 異常フラグ
- アラート閾値設定（システム）

## 出力 / 結果
- リアルタイム取引一覧（ステータス遷移可視化）
- 異常検知一覧（dispute / refund 急増 / Stripe 同期エラー等）
- 各取引の詳細

## ビジネスルール
- BR-55-01: ダッシュボードは 30 秒ごとに自動更新。
- BR-55-02: 異常検知の自動アラート対象:
  - 同看護師の 24h 内キャンセル 3 件以上
  - dispute 発生
  - Stripe 同期失敗
  - Authorization → 7 日経過 + 未 Capture
  - 大口取引（[仮決定]: 50000 円以上）
- BR-55-03: 各取引閲覧は監査ログ記録。
- BR-55-04: 一括 CSV エクスポートは FR-58 連動。

## 受入基準（AC）

### AC-55-01: ダッシュボード表示
```gherkin
Given 当日取引 100 件
When 運営がダッシュボードを開く
Then ステータス別件数 + 異常検知バッジが表示
```

### AC-55-02: 異常アラート
```gherkin
Given 看護師 N-001 が 24h 内に 4 件キャンセル
Then 異常アラートが発火
And 運営ダッシュボードに高優先度表示
And メール / Slack 通知（FR-56）
```

### AC-55-03: 取引詳細
```gherkin
When 運営が個別取引を開く
Then タイムライン（申込→承認→指示書→決済等）が表示
And 監査ログに閲覧記録
```

## サブ機能
- FR-55-1: リアルタイム監視
- FR-55-2: 異常検知ルールエンジン
- FR-55-3: 取引詳細
