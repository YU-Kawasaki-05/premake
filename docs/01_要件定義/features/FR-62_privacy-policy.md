# FR-62: プライバシーポリシーページ

## 概要
プライバシーポリシーの公開ページ。個人情報・医療データの取扱い・第三者提供条件・保管期間等を明示。

## ビジネスルール
- BR-62-01: 個人情報保護法・APPI ガイドライン準拠。
- BR-62-02: 医療データ（施術記録 / 同意書 / 指示書）の特別扱いを明記。
- BR-62-03: 保管期間（医療記録 7 年、その他は要件に応じて）を明示。
- BR-62-04: バージョン管理 + 改定通知（FR-61 と同様）。
- BR-62-05: 利用客（ゲスト）の個人情報取扱を別セクションで詳述。

## 受入基準（AC）

### AC-62-01: 公開
```gherkin
When ゲストが /privacy にアクセス
Then 最新版が表示
```

### AC-62-02: 改定再同意
```gherkin
Given v2 公開
When ユーザーログイン
Then 再同意ダイアログ
```

### AC-62-03: 第三者提供同意
```gherkin
Given 医療データを医療機関のカルテと連携
Then 同意取得時に明示同意（チェックボックス）必須
And 同意ログ保持
```

## サブ機能
- FR-62-1: 公開ページ
- FR-62-2: バージョン管理
- FR-62-3: データ取扱詳細
