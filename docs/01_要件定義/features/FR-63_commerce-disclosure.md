# FR-63: 特商法表記

## 概要
特定商取引法に基づく表記ページ。プラットフォーム提供者情報・料金・支払方法・返金条件・問い合わせ先を法定情報として公開。

## ビジネスルール
- BR-63-01: 表記項目（特商法 11 条準拠）:
  - 販売事業者
  - 代表者
  - 所在地
  - 連絡先（電話・メール）
  - 商品 / サービス内容
  - 料金 / 手数料率
  - 支払方法（クレジットカード・Stripe）
  - 引渡時期
  - 返品 / キャンセル条件（FR-41 連動）
- BR-63-02: 内容変更は法務確認後に反映。
