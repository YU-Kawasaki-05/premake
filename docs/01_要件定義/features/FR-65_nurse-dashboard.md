# FR-65: 看護師ダッシュボード

## 概要
看護師（U-01）のホーム画面。今日のタスク・直近予約・売上・指示書ステータス・通知を集約。

## アクター
- U-01 看護師

## 構成要素
- 今日のタスクカード（指示書未確認 / 施術記録未投入 / 予約承認待ち）
- 今日の予約（時間順）
- 今週の予約一覧
- 直近 30 日の売上サマリ + 月次グラフ
- 顧客予約ページ URL（FR-69）コピー機能
- 通知センター（最新 10 件）
- 重要バナー（免許審査中 / カード未登録 等）

## ビジネスルール
- BR-65-01: 今日のタスクは優先度ソート（緊急度高）。
- BR-65-02: 売上サマリは確定値・速報値を区別表示。
- BR-65-03: ダッシュボードは初回訪問時にウォークスルー（onboarding）表示（[仮決定]、初回のみ）。
- BR-65-04: 主要 API は集約エンドポイントで 1 リクエストで取得（NFR-PERF）。

## 受入基準（AC）

### AC-65-01: 今日のタスク表示
```gherkin
Given 指示書未確認 1 件 + 施術記録未投入 2 件
When ダッシュボード表示
Then タスクカードに「タスク 3 件」が表示
And クリックで該当画面へ遷移
```

### AC-65-02: 売上サマリ
```gherkin
Given 過去 30 日の completed 予約
Then 売上サマリと月次グラフが表示
And 「速報値含む」バッジ
```

### AC-65-03: 顧客予約ページ URL コピー
```gherkin
When 「URL コピー」ボタンクリック
Then クリップボードにコピー
And 「コピーしました」トースト
```

### AC-65-04: 重要バナー
```gherkin
Given 免許審査中
Then 上部に黄色バナー「審査中」+ 残日数目安
```

- FR-65-2: 売上ウィジェット
- FR-65-3: URL コピー
- FR-65-4: ウォークスルー
