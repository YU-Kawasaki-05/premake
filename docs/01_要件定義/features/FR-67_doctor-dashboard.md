# FR-67: 指示医ダッシュボード

## 概要
指示医（U-03）のホーム画面。指示書発行待ち / 施術記録確認待ち / 担当予約のスケジュールを優先表示。

## 構成要素
- 指示書発行待ち（FR-29 への CTA、緊急度ソート）
- 施術記録確認待ち（FR-34 への CTA、SLA 表示）
- 今日の担当予約
- 今週の担当予約
- 異変・特記事項のあった記録（要レビュー、ハイライト）
- 重要バナー（医師免許審査中 等）

## ビジネスルール
- BR-67-01: 指示書発行待ちは緊急度（施術開始時刻接近）順。
- BR-67-02: SLA 接近（72h 接近）の確認待ちは強調表示。
- BR-67-03: モバイル表示で電子署名フローまで完結可能（出先での発行を想定）。

## 受入基準（AC）

### AC-67-01: 指示書発行待ち
```gherkin
Given 発行待ち 2 件（最近 1h 後と 3 日後）
Then 1h 後が最上部 + 緊急度警告色
And 3 日後はその下
```

### AC-67-02: 異変記録ハイライト
```gherkin
Given 異変記録ありの確認待ち
Then 専用バナー「異変記録: 1 件」が表示
And クリックで詳細へ
```

### AC-67-03: モバイル発行
```gherkin
Given スマホで開いている
When 「発行」をタップ
Then モバイル UI で電子署名（TOTP 入力）フローが完結
```

## サブ機能
- FR-67-1: 発行待ちリスト
- FR-67-2: 確認待ちリスト
- FR-67-3: 異変ハイライト
