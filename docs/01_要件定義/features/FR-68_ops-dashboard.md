# FR-68: 運営 KPI ダッシュボード

## 概要
プラットフォーム全体の KPI を運営に提示。GMV / 手数料収益 / アクティブユーザー / 異常検知 / SLA 状況を集約。

## 構成要素
### KPI（リアルタイム / 当日・当月・前月比）
- GMV（取扱高）
- プラットフォーム手数料収益
- アクティブ看護師数 / アクティブ施設数
- 予約成立率 / キャンセル率
- 平均施術単価
- リピート率（看護師 / 利用客）

### 運用状態
- 審査キュー残数（FR-54）+ SLA 警告
- 違反案件数（FR-56）+ 重大度別
- Stripe 同期エラー / dispute 件数
- システム正常性（FR-80 連動）

### グラフ
- 月次 GMV / 手数料 / 予約数の推移
- 地域別ヒートマップ
- 施設別ランキング

## ビジネスルール
- BR-68-01: KPI は 1 分粒度でキャッシュ更新（NFR-PERF）。
- BR-68-02: 前月比 / 前年比を必ず併記。
- BR-68-03: アラート閾値超過時は即時バナー表示。
- BR-68-04: ダウンロード可（CSV / PNG / PDF）。

## 受入基準（AC）

### AC-68-01: KPI 表示
```gherkin
When 運営がダッシュボードを開く
Then 主要 KPI が当日・当月・前月比で表示
```

### AC-68-02: アラート
```gherkin
Given dispute が前日比 +200%
Then ダッシュボード上部にアラートバナー
And Slack 通知 (FR-56)
```

### AC-68-03: 地域ヒートマップ
```gherkin
Then 全国地図上で都道府県別 GMV がヒートマップ表示
And クリックで詳細
```

## サブ機能
- FR-68-1: KPI 集計
- FR-68-2: グラフ・ヒートマップ
- FR-68-3: アラート連動
