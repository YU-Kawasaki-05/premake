# FR-70: 利用客のゲスト予約

## 概要
利用客（U-05）が看護師の公開ブッキングページから予約を申し込む。会員登録不要のゲスト予約。メール + 電話番号 + SMS 認証で本人特定。

## アクター
- U-05 利用客（ゲスト）

## 入力データ
| フィールド | 型 | 必須 | 制約 |
|-----------|---|------|------|
| nurse_page_handle | string | ○ | URL から |
| menu_id | uuid | ○ | 予約するメニュー |
| 希望日時 | datetime range | ○ | 空き枠から選択 |
| 氏名 | string | ○ | 1〜100 文字 |
| 氏名（カナ） | string | ○ | 全角カナ |
| メール | string | ○ | RFC5322 |
| 電話番号 | string | ○ | E.164 |
| 生年月日 | date | ○ | 18 歳未満は保護者同意必須 |
| 性別 | enum | × | - |
| 連絡希望時間 | string | × | - |
| 自由メモ | string | × | 〜500 文字 |
| SMS 認証コード | string | ○ | 6 桁数字 |

## 出力 / 結果
- `customer_bookings` レコード作成（status=tentative）
- SMS 認証成功で status=confirmed
- 看護師に通知 + 同意書記入リンク（FR-32）+ 問診票リンク（FR-72）を利用客にメール / SMS

## ビジネスルール
- BR-70-01: SMS 認証は同電話番号に対して 1 時間あたり 5 回まで（spam 防止）。
- BR-70-02: SMS 認証コードは 5 分有効、3 回失敗で再発行が必要。
- BR-70-03: 18 歳未満は保護者同意フォームが追加表示。
- BR-70-04: 看護師のブッキングページ設定（事前決済 / カウンセリング）に応じて次ステップが変化。
- BR-70-05: 予約成立条件:
  - SMS 認証完了
  - 事前決済（必要な場合は完了）
  - 同意書 / 問診票（看護師設定で必須化されていれば完了）
- BR-70-06: 看護師の確保するスペース枠とメニュー時間が整合（FR-69 連動）。
- BR-70-07: customer_bookings は users とは別テーブル（DEC-12: アカウント不要）。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| SMS 認証コード誤り | 残り試行回数表示 |
| 既に同時刻に他予約 | 「指定時刻は予約済みです」 |

## 受入基準（AC）

### AC-70-01: 予約フロー
```gherkin
Given 利用客が /n/yamada-nurse を開く
When メニュー「眉」+ 6/15 14:00 を選択 + 個人情報入力
And SMS 認証コード入力 → OK
Then customer_bookings status=confirmed
And 看護師に通知メール
And 利用客に確認メール + SMS（FR-73）
And 同意書 / 問診票リンクが利用客に届く
```

### AC-70-02: 18 歳未満
```gherkin
Given 生年月日から 16 歳
Then 保護者氏名 / 続柄 / 連絡先入力フォーム追加
And 保護者にも別途同意 SMS / メール
```

### AC-70-03: 事前決済必須の場合
```gherkin
Given 看護師が「事前決済必須」設定
When 予約フォームの最後で「決済して確定」
Then Stripe Elements で決済 → 即時 capture
And status=confirmed
```

### AC-70-04: 看護師のスペース枠と整合
```gherkin
Given 看護師が 6/15 14-16 にスペース予約
And メニュー「眉」(60 分)
When 利用客が 6/15 14:00 を選択
Then OK
When 6/15 17:00 を選択
Then 「指定時刻は受付不可」（看護師のスペース枠外）
```

### AC-70-05: 重複予約防止
```gherkin
Given 同一電話番号が 6/15 14:00 に既存予約
When 別看護師の予約を 6/15 14:30 で申込（同利用客判定）
Then 重複警告（情報提供のみ、ブロックはしない）
```
