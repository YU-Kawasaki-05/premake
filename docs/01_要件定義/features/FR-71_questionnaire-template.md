# FR-71: 問診票テンプレート編集

## 概要
看護師（U-01）が利用客（U-05）に提出させる問診票のテンプレートを編集する。プラットフォーム標準テンプレート + 看護師ごとのカスタマイズ。

## アクター
- U-01 看護師

## 入力データ
| フィールド | 型 | 必須 | 制約 |
|-----------|---|------|------|
| sections | array | ○ | { question, type, required, options } の配列 |
| version | int | ○ | 自動採番 |

### 質問タイプ
- single_choice / multiple_choice / text / number / date / yes_no

## 標準テンプレート（必須項目）
- アレルギー有無
- 服用中の薬
- 既往歴（皮膚疾患・アトピー等）
- 妊娠 / 授乳の可能性
- 過去のアートメイク経験
- 当日の体調

## ビジネスルール
- BR-71-01: 標準必須項目は削除不可（医療リスク確認のため）。
- BR-71-02: 看護師がカスタム質問追加可。
- BR-71-03: バージョン管理（FR-31 と同様）。記入済み問診票は記入時バージョンを保持。
- BR-71-04: 個人情報質問（住所等）は不要であれば追加しない原則（最小化）。
- BR-71-05: 問診票記入結果は指示書発行時に医師（U-03）が必ず確認する。

## 受入基準（AC）

### AC-71-01: 標準ベースで編集
```gherkin
Given U-01 が初めてテンプレートを開く
Then 標準テンプレートが基礎に表示
When カスタム質問「希望のデザインタイプ」を追加 + 保存
Then 自分用テンプレート v1 が作成
```

### AC-71-02: 必須項目削除不可
```gherkin
Given「アレルギー有無」を削除しようとする
Then 削除 disabled、ツールチップで「法令上必須」
```

### AC-71-03: バージョン管理
```gherkin
Given v1 で記入済み 5 件
When v2 公開
Then 既存 5 件は v1 で保持
And 新規記入は v2
```

- FR-71-3: バージョン管理
