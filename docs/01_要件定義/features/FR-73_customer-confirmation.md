# FR-73: 確認メール / SMS（利用客）

## 概要
利用客（U-05）の予約完了 / 変更 / 当日リマインドを確実に伝えるため、メール + SMS 両方で送信。

## トリガー
- 予約完了 (FR-70)
- 予約変更 (FR-75)
- 予約キャンセル (FR-75 / 看護師都合)
- 施術前日リマインド
- 施術 1h 前リマインド
- 同意書 / 問診票記入リンク
- 事前決済成功 / 失敗

## ビジネスルール
- BR-73-01: 予約完了時はメール + SMS の両方送信（DEC-12 のメール+電話番号で本人特定）。
- BR-73-02: SMS は 70 文字以内、URL 短縮（自社ドメイン）+ 重要情報のみ。
- BR-73-03: メールは詳細情報を含む。
- BR-73-04: SMS はオプトアウト不可（重要事項のため）。
- BR-73-05: 配信失敗時は当該予約を看護師にエスカレーション。

## 受入基準（AC）

### AC-73-01: 予約完了通知
```gherkin
Given 利用客 booking が confirmed
Then メール + SMS 即時送信
And SMS 内容: 「予約確定 6/15 14:00 詳細: {URL}」
```

### AC-73-02: 前日リマインド
```gherkin
Given 施術前日 18 時
Then 利用客にメール + SMS リマインド
```

### AC-73-03: 配信失敗エスカレーション
```gherkin
Given 利用客の電話番号が無効
And SMS 送信失敗
Then 看護師に「利用客連絡先確認依頼」通知
```

## サブ機能
- FR-73-1: 各イベント送信
- FR-73-2: 配信失敗エスカレーション
