# FR-74: 予約照会（メール+番号）

## 概要
利用客（U-05）が会員登録なしで自分の予約を照会できる。メールアドレス + 予約番号 + SMS 認証コードで認証。

## アクター
- U-05 利用客

## 入力データ
| email | string | ○ | RFC5322 |
| 予約番号 | string | ○ | 8 桁英数字 |
| SMS 認証コード | string | ○ | 6 桁、5 分有効 |

## 出力 / 結果
- 一時セッション（30 分）発行
- 自分の予約一覧 + 詳細閲覧可能
- 予約変更 / キャンセル（FR-75）の起点

## ビジネスルール
- BR-74-01: メール + 予約番号 + SMS 三要素認証（PII 保護）。
- BR-74-02: 一時セッションは 30 分で自動失効。
- BR-74-03: 1 時間あたり同一メールで照会試行 5 回まで（spam 防止）。
- BR-74-04: 照会した予約 detail で利用客自身の個人情報のみ表示（看護師の他予約は見えない）。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| 認証情報不一致 | 「該当する予約が見つかりません」（メール存在を漏らさない） |
| 試行回数超過 | 429 |

## 受入基準（AC）

### AC-74-01: 正常照会
```gherkin
When 正しいメール + 予約番号 + SMS 認証コード
Then 一時セッション発行 + 予約詳細表示
```

### AC-74-02: 不一致
```gherkin
When 不正な組み合わせ
Then 「該当予約が見つかりません」（区別なし）
```

### AC-74-03: 一時セッション失効
```gherkin
Given 30 分経過
When 詳細画面でアクション
Then 401、再認証要求
```

## サブ機能
- FR-74-1: 三要素認証
- FR-74-2: 一時セッション
