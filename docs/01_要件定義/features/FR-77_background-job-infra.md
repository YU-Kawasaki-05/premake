# FR-77: バックグラウンドジョブ基盤

## 概要
非同期処理基盤。メール送信 / PDF 生成 / Stripe 同期 / 集計 / リマインド / 自動キャンセル等を支える。

## アクター
- システム

## ジョブカテゴリ（β段階）
- 通知: メール送信 / SMS 送信
- ドキュメント: PDF 生成 / 暗号化処理
- 決済: Stripe 同期 / Capture / Transfer / Refund
- リマインド: 24h 前 / 1h 前 / SLA 切れ
- 自動処理: 48h 承認待ち自動キャンセル / Authorization 期限切れ再オーソリ
- 集計: KPI 集計 / 月次明細生成
- エクスポート: CSV / PDF 大規模生成

## 必要機能
- ジョブキュー（タイプ別優先度）
- スケジュール実行（cron 風）
- リトライ（指数バックオフ）+ 最大リトライ後 Dead Letter Queue
- 冪等性キー（idempotency_key）
- 同時実行数制御（per-job-type）
- ダッシュボード（実行履歴・失敗率・遅延）

## ビジネスルール
- BR-77-01: 重要ジョブ（決済 / 指示書 PDF）は最高優先度キュー、低優先度ジョブと分離。
- BR-77-02: リトライは指数バックオフ（30s, 1m, 5m, 15m, 1h, 6h）、6 回失敗で DLQ。
- BR-77-03: 同一 idempotency_key の重複ジョブは 1 回のみ実行。
- BR-77-04: ジョブ失敗の運営通知は重要度別（決済系は即時、メール系は集計通知）。
- BR-77-05: スケジュール実行は分散ロック（複数インスタンスでも 1 回実行）。

## 受入基準（AC）

### AC-77-01: ジョブ投入と実行
```gherkin
Given 予約承認時にメール送信ジョブ投入
When 数秒以内にワーカーが処理
Then メール送信、ジョブ状態=succeeded
```

### AC-77-02: リトライ
```gherkin
Given メール送信が一時的エラー
Then 30s 後にリトライ
When 6 回全失敗
Then DLQ に退避、運営アラート
```

### AC-77-03: 冪等性
```gherkin
Given 同一 idempotency_key のジョブが 2 回投入
Then 1 回目: 実行
And 2 回目: スキップ（既処理として記録）
```

### AC-77-04: スケジュール実行
```gherkin
Given 「48h 承認待ち自動キャンセル」が cron 5 分間隔
When 複数インスタンス起動中
Then 1 インスタンスのみ実行（分散ロック）
```

### AC-77-05: 監視ダッシュボード
```gherkin
When 運営がジョブ監視画面（FR-68 内 or 別画面）を開く
Then 各ジョブタイプの実行件数・失敗率・遅延が表示
```
