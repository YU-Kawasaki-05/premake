# FR-85: 法人レベルダッシュボード

## 概要
法人管理者（U-06）のホーム画面。配下全施設の横断 KPI と各施設へのドリルダウン。

## 構成要素
- 法人レベル KPI（合計 GMV / 受取手数料控除後 / 稼働率平均 / 予約数）
- 施設別ランキング（収益 / 稼働率）
- 施設別状態カード（承認待ち / 違反 / Stripe 連携）
- 招待管理（FR-84 への CTA）
- 法人プロフィール状態（FR-82）

## ビジネスルール
- BR-85-01: 法人配下のみ集計。他法人データは閲覧不可。
- BR-85-02: 重要事項（連携問題 / 違反案件）は施設別カードに警告色。
- BR-85-03: 法人内ベンチマーク機能（施設間の稼働率比較）。

## 受入基準（AC）

### AC-85-01: 法人レベル KPI
```gherkin
Given 法人配下 3 施設
Then 合算 KPI と各施設別表示
```

### AC-85-02: ベンチマーク
```gherkin
Given 3 施設の稼働率が 80% / 50% / 30%
Then 平均ライン + 各施設の上下を可視化
```

### AC-85-03: ドリルダウン
```gherkin
When 施設カードクリック
Then 該当施設の FR-66 ダッシュボードへ遷移
```

## サブ機能
- FR-85-1: 横断集計
- FR-85-2: 施設別ベンチマーク
- FR-85-3: ドリルダウン
