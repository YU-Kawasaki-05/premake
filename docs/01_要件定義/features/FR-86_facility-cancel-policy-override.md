# FR-86: 施設別キャンセルポリシー上書き

## 概要
施設または法人が独自のキャンセルポリシーを設定し、共通ポリシー（FR-41）を上書きする。設定なき施設はデフォルトを使用。

## アクター
- U-02 施設管理者（自施設）
- U-06 法人管理者（自法人配下）

## 入力データ
| フィールド | 型 | 必須 | 制約 |
|-----------|---|------|------|
| facility_id (or org_id) | uuid | ○ | - |
| policy | array | ○ | { hours_before, refund_rate, applies_to } の配列 |
| 看護師通知方法 | enum | × | 予約申込時に明示 |
| 有効開始日 | date | ○ | 現在以降。既予約には適用しない |

## 出力 / 結果
- `cancel_policy_overrides` レコード作成
- 検索結果・予約詳細に「特別ポリシー」バッジ表示

## ビジネスルール
- BR-86-01: 既予約には旧ポリシー保証（FR-41 BR-04 と同じ）。
- BR-86-02: 上書きは共通ポリシーの **緩和方向にのみ** 可（[仮決定]: 看護師に不利な厳格化は不可、Phase 2 で再検討）。
- BR-86-03: 看護師には予約申込時に「この施設の特別ポリシー」が表示される。
- BR-86-04: 法人配下の場合、法人レベルと施設レベルの上書きは併存可（施設レベルが優先）。

## エラーケース
| 条件 | 期待挙動 |
|------|----------|
| 共通ポリシーより厳しい設定 | 「看護師に不利な変更はできません」 |

## 受入基準（AC）

### AC-86-01: 施設による緩和
```gherkin
Given 共通ポリシーの 3-7 日前は返金 50%
When U-02 が 3-7 日前は 80% 返金 に上書き
Then 上書き保存される
And 該当施設の予約は 80% 返金になる
```

### AC-86-02: 厳格化の禁止
```gherkin
Given 共通ポリシーの 7 日前以前は返金 100%
When U-02 が 7 日前以前を 70% に上書きを試みる
Then エラー「看護師に不利な変更はできません」
```

### AC-86-03: 既予約に旧ポリシー適用
```gherkin
Given 上書き前の予約 B-001
When 上書き後にキャンセル
Then 旧ポリシー（共通）が適用
```

### AC-86-04: 法人と施設の併存
```gherkin
Given 法人レベルで「3-7 日前 70%」上書き
And 配下 F-001 で「3-7 日前 90%」上書き
When F-001 の予約をキャンセル
Then F-001 の上書きが優先（90%）
```

## サブ機能
- FR-86-1: 上書き設定
- FR-86-2: 緩和制約バリデーション
- FR-86-3: 法人 / 施設レベルの優先順位
