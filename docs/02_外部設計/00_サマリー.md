# Phase 2 サマリー — premake / 外部設計

> Phase 1（要件定義）の 88 機能 / 6 ユーザー / 100+ 画面を、技術的に実装可能な設計に展開した。

---

## 1. 設計概要

**スタック**: Next.js 15 (App Router) + Server Actions + TypeScript / Supabase (Postgres + Auth + Storage) / Vercel / Stripe Connect / Resend / Twilio / Sentry / Axiom / 自前 worker_jobs (β は Inngest 不採用、コスト最小)。

**設計の中核**:
- DB は **60 テーブル**を 8 カテゴリ + 横断で構造化、RLS で多層防御
- API は **188 エンドポイント**を Server Action / Route Handler に分類、将来モバイル拡張も見据える
- 権限は **RBAC + テナント属性**、3 層防御（Middleware → ハンドラ → RLS）
- 画面は **100+ SCR**、Tailwind + shadcn/ui で一貫した医療系トーン
- NFR は **9 カテゴリ × 50+ 項目**、SLO・コンプライアンス・観測性をカバー
- テストは **Unit:Integration:E2E = 70:25:5**、AC ↔ テストを `@verifies` で双方向追跡

## 5. Phase 3（技術設計）への引き継ぎ

### 5.1 技術選定が確定済み（DEC-20〜29）
- 上記参照

### 5.2 実装で詳細化が必要な事項
