## 2. リレーション概要図

```mermaid
graph LR
    Org[organizations] --> Fac[facilities]
    Fac --> Spc[spaces]
    Fac --> DocAssign[doctor_facility_assignments]
    Users --> DocAssign
    Spc --> Pricing[space_pricing]
    Spc --> Avail[space_availability_*]
    Spc --> Bk[bookings]
    Users --> Bk
    Bk --> Sess[booking_sessions]
    Sess --> Pres[prescriptions]
    Pres --> PresPdf[prescription_pdfs]
    Sess --> TR[treatment_records]
    TR --> TRImg[treatment_record_images]
    Bk --> Pay[payments]
    NursePage[nurse_pages] --> CB[customer_bookings]
    CB --> Sess
    CB --> CC[customer_consents]
    CB --> CQR[customer_questionnaire_responses]
    CB --> CPay[customer_payments]
```

## 3. テナント階層

```mermaid
graph TB
    Platform[premake プラットフォーム]
    Platform --> Org1[Organization A 法人]
    Platform --> Org2[Organization B 法人]
    Platform --> FacIndep[独立施設 C]
    Org1 --> Fac1[Facility A1]
    Org1 --> Fac2[Facility A2]
    Org2 --> Fac3[Facility B1]
    Fac1 --> Sp1[Space x N]
    Fac1 --> Doc1[指示医割当 x N]
    Fac1 --> Adm1[施設管理者 x N]
```

- 法人 (organizations) は 1〜N 施設 (facilities) を持つ
- 独立施設は organization_id = NULL
- 各施設は複数のスペース・指示医・管理者を持つ
- 看護師 (users with role=nurse) は施設に所属しない（プラットフォーム横断）

## 4. データフローの中核 6 系統

| 系統 | 流れ |
|---|---|
| **予約成立** | spaces × bookings × booking_sessions |
| **指示書フロー** | booking_sessions → prescriptions → prescription_pdfs |
| **施術記録** | booking_sessions → treatment_records → treatment_record_images |
| **決済** | bookings → payments → (refunds) |
| **顧客予約** | nurse_pages → customer_bookings → (customer_consents, customer_questionnaire_responses, customer_payments) |
| **監査・通知** | 全業務テーブル → audit_log / notifications |
