## 凡例

- **◎ 全データ可**: テーブル全体を閲覧・操作可（運営など）
- **○ 自分関連のみ**: 自分の user_id / facility_id / organization_id に紐づくものだけ
- **△ 限定**: 監査用のマスキング閲覧、または特定条件のみ
- **× 不可**: 当該ロールはアクセス不可
