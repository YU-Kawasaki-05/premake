# 権限設計 — 認証フロー（シーケンス図）

> [00_index.md](00_index.md) に戻る

## 1. メールサインアップ → 看護師として完全機能まで

```mermaid
sequenceDiagram
    participant U as User Browser
    participant N as Next.js
    participant SA as Supabase Auth
    participant DB as Postgres
    participant ML as Mail (Resend)

    U->>N: POST /api/v1/auth/signup/nurse
    N->>SA: signUp(email, password)
    SA->>DB: auth.users INSERT
    N->>DB: users INSERT (role=nurse, status=email_unverified)
    N->>ML: send confirm email
    ML->>U: 確認メール
    U->>N: GET /api/v1/auth/email/verify?token=...
    N->>DB: users.email_verified=true
    N->>U: ダッシュボードへ
    U->>N: POST /api/v1/auth/licenses/nurse (画像 + 籍番号)
    N->>DB: nurse_license_applications INSERT
    N->>DB: users.license_status=pending_review
    Note over N,DB: 運営審査待ち
    Note over N: U-04 が EP-H007 で承認
    N->>DB: users.license_status=approved, can_book=true
    N->>SA: app_metadata 更新（license_status, can_book）
    N->>U: 機能解放通知
```

## 2. 招待型サインアップ（施設管理者）

```mermaid
sequenceDiagram
    participant Inviter as 運営/法人管理者
    participant N as Next.js
    participant DB
    participant ML as Mail
    participant Invitee as 招待先

    Inviter->>N: POST /api/v1/invitations
    N->>DB: invitations INSERT (token, expires_at, facility_id)
    N->>ML: 招待メール
    ML->>Invitee: 招待リンク

    Invitee->>N: GET /invite/{token}
    N->>DB: SELECT invitations WHERE token=...
    N->>Invitee: 招待受諾画面
    Invitee->>N: POST /api/v1/auth/invitations/{token}/accept (password, name, ...)
    N->>SA: signUp
    N->>DB: users INSERT (role=facility_admin, facility_id=..., status=email_verified)
    N->>DB: invitations.consumed_at SET
    N->>SA: app_metadata.facility_id 設定
    N->>Invitee: ダッシュボードへ
```

## 3. ログイン + MFA

```mermaid
sequenceDiagram
    participant U as User
    participant N
    participant SA as Supabase Auth
    participant DB

    U->>N: POST /api/v1/auth/login
    N->>SA: signInWithPassword
    SA->>N: { aal: aal1, mfa_required: true (factor: totp) }
    N->>U: { mfa_required: true }（一時セッション）
    U->>N: POST /api/v1/auth/mfa/verify { code }
    N->>SA: mfa.challengeAndVerify
    SA->>N: { aal: aal2, session: ... }
    N->>U: Set-Cookie sb-access-token
    Note over N,U: 以降のリクエストは aal2 で認証
```

## 4. 電子指示書発行（aal2 必須）

```mermaid
sequenceDiagram
    participant D as Doctor
    participant N
    participant SA
    participant DB
    participant TSA as TSA (RFC 3161)

    D->>N: POST /api/v1/prescriptions
    N->>SA: getAAL → aal2 確認
    alt aal1 のみ
        N->>D: 403 MFA_REQUIRED
        D->>N: MFA verify
    end
    N->>D: TOTP 再入力リクエスト
    D->>N: code
    N->>SA: verify TOTP code
    N->>N: signature_x509 生成
    N->>TSA: get timestamp_token
    TSA->>N: token
    N->>DB: prescriptions INSERT (status=issued, signed_at, signature_x509, timestamp_token)
    N->>DB: worker_jobs.generate_prescription_pdf キュー
    N->>D: 201
```

## 5. 利用客（ゲスト）SMS OTP 認証

```mermaid
sequenceDiagram
    participant C as Customer Browser
    participant N as Next.js
    participant DB
    participant T as Twilio

    C->>N: POST /api/c/n/{handle}/bookings/draft (個人情報入力)
    N->>DB: customer_bookings INSERT (status=tentative)
    N->>T: send SMS OTP to phone
    T->>C: SMS code "123456"
    C->>N: POST /api/c/bookings/{draft_token}/verify-sms { code }
    N->>DB: customer_bookings.sms_verified_at, status=confirmed
    N->>N: guest_session JWT 生成 (30 分)
    N->>C: Set-Cookie: guest_session=...; HttpOnly; 30min
    C->>N: GET /api/c/bookings (with guest session)
    N->>N: verify guest_session
    N->>DB: SELECT customer_bookings (Service Role + customer_booking_id 限定)
    N->>C: 200
```

## 6. 予約照会（メール + 番号 + OTP）

```mermaid
sequenceDiagram
    participant C
    participant N
    participant DB
    participant T as Twilio

    C->>N: POST /api/c/lookup/request-otp { email, booking_number, phone_last4 }
    N->>DB: SELECT customer_bookings WHERE email=... AND number=... AND phone LIKE %last4
    alt 該当あり
        N->>T: send SMS OTP
        T->>C: SMS
    end
    N->>C: 200 (常に成功扱い)
    C->>N: POST /api/c/lookup/verify-otp { email, booking_number, code }
    N->>N: verify OTP
    N->>C: Set-Cookie guest_session
```

## 7. パスワードリセット

```mermaid
sequenceDiagram
    participant U
    participant N
    participant SA
    participant ML

    U->>N: POST /api/v1/auth/password-reset/request { email }
    N->>SA: resetPasswordForEmail
    SA->>ML: send link (token 30min)
    ML->>U: メール
    N->>U: 200 (常に成功扱い)
    U->>N: GET /password-reset?token=...
    U->>N: POST /api/v1/auth/password-reset/confirm { token, new_password }
    N->>SA: updateUser({ password })
    N->>SA: signOut all sessions
    N->>U: 200 + 再ログイン要求
```

## 8. Stripe Webhook 受信（決済確定）

```mermaid
sequenceDiagram
    participant S as Stripe
    participant N as Webhook Endpoint
    participant DB
    participant J as Job Queue

    S->>N: POST /api/webhooks/stripe (event)
    N->>N: verify signature
    N->>DB: stripe_events INSERT (PK = event.id, idempotent)
    N->>S: 200 OK (即時)
    N->>J: queue process_stripe_event job
    Note over J: バックグラウンドで処理
    J->>DB: payments / refunds 等更新
    J->>DB: audit_log
```
