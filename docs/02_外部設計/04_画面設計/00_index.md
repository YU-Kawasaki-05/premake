## ワイヤー記述

各画面は以下を含める:

- **URL**
- **関連 FR / EP**
- **対象ユーザー**
- **レイアウト** (Mermaid または ASCII でワイヤー)
- **要素一覧表** (種別 / 必須 / バリデーション / バインドする EP / 備考)
- **インタラクション** (操作 → 遷移)
- **エラー状態** (バリデーション / 通信 / 権限)
- **ローディング状態**
- **空状態 (Empty State)**
- **モバイル対応の差分**

## デザイン原則（DEC-06 を踏まえた高品質方針）

1. **クリーン**: 余白を生かし、情報過多を避ける
2. **医療らしい信頼感**: 落ち着いた色（青系・グレー）+ アクセントは抑えめ
3. **視認性**: コントラスト比 WCAG AA、フォントサイズ最低 14px (本文)
4. **応答性**: ローディング・成功・失敗のフィードバックが即時
5. **モバイルファースト**: 看護師は移動中スマホ、施設管理は PC
6. **アクセシビリティ**: キーボード操作・スクリーンリーダー対応
