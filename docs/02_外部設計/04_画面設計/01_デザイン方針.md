# 画面設計 — デザイン方針

> [00_index.md](00_index.md) に戻る

## 1. デザインシステム

### 1.1 採用ライブラリ (DEC-28)
- **Tailwind CSS** (v4)
- **shadcn/ui** (Radix UI ベース、コピー＆カスタマイズ)
- **Lucide React** (アイコン)
- **react-hook-form + zod** (フォーム)
- **TanStack Query** (クライアント側データ取得)

### 1.2 カラーパレット

```css
/* Tailwind config */
:root {
  /* Brand */
  --primary: 220 70% 50%;          /* 落ち着いた青 (信頼感) */
  --primary-foreground: 0 0% 100%;

  /* Surface */
  --background: 0 0% 100%;
  --foreground: 220 15% 15%;
  --muted: 220 10% 95%;
  --muted-foreground: 220 10% 45%;
  --border: 220 15% 90%;

  /* Accent */
  --accent: 200 75% 55%;            /* シアン寄り */
  --accent-foreground: 0 0% 100%;

  /* Status */
  --success: 145 60% 45%;
  --warning: 35 90% 55%;
  --destructive: 0 70% 50%;
  --info: 215 75% 55%;

  /* Dark mode は β 後 */
}
```

### 1.3 タイポグラフィ

- **ベースフォント**: Inter（英数）+ Noto Sans JP（日本語）
- **フォントサイズスケール**:
  - xs: 12px (補助テキスト)
  - sm: 14px (本文小)
  - base: 16px (本文)
  - lg: 18px (見出し小)
  - xl: 20px (見出し中)
  - 2xl: 24px (見出し大)
  - 3xl: 30px (ページタイトル)

### 1.4 スペーシング

Tailwind のデフォルト 4px ベースを使用。
- セクション間: 32〜48px
- カード内パディング: 16〜24px
- フォーム要素間: 12〜16px

### 1.5 角丸

- ボタン / カード / 入力: `rounded-lg` (8px)
- バッジ: `rounded-full`

### 1.6 シャドウ

```css
shadow-sm    : box-shadow: 0 1px 2px rgb(0 0 0 / 0.04);
shadow-md    : box-shadow: 0 4px 6px rgb(0 0 0 / 0.06);
shadow-lg    : box-shadow: 0 10px 15px rgb(0 0 0 / 0.08);
```

## 2. レスポンシブ方針

| breakpoint | デバイス | 主な対象 |
|---|---|---|
| sm (640px) | スマホ大 | 看護師（移動中）、利用客 |
| md (768px) | タブレット | 看護師（施術直前確認） |
| lg (1024px) | 小型 PC | 施設管理者・指示医 |
| xl (1280px+) | デスクトップ | 運営・施設管理者 |

**モバイルファースト**:
- 看護師ダッシュボード・予約申込・公開ページは sm から完璧に動く
- 運営画面は lg 以上前提（モバイル対応は最低限）

## 3. アクセシビリティ (WCAG 2.1 AA)

### 3.1 必須要件
- カラーコントラスト 4.5:1 以上（本文）/ 3:1 以上（大テキスト）
- すべてのインタラクション要素にフォーカスインジケータ
- フォームに `<label>` 必須（visible label or aria-label）
- ARIA 属性で動的 UI を補完
- キーボードのみで全操作可能
- スクリーンリーダー (NVDA / VoiceOver) で読める

### 3.2 ツール
- 開発: axe-core（自動テスト）
- レビュー: WAVE / Lighthouse a11y スコア 95+
- E2E: Playwright + axe-playwright

## 4. パフォーマンス

| 指標 | 目標 |
|---|---|
| LCP | < 2.5s |
| INP | < 200ms |
| CLS | < 0.1 |
| TBT | < 300ms |
| Lighthouse スコア | 90+ |

施策:
- React Server Components 主体（クライアント JS 最小化）
- Next.js Image で画像最適化
- フォント: Next.js `next/font` で self-host
- ルートベース code splitting

## 5. アニメーション・モーション

- **Framer Motion** で要所のみ（ローディング・モーダル開閉）
- `prefers-reduced-motion` を尊重
- 過度な動きは避ける（医療系 = 落ち着き）

## 6. 国際化（i18n）

- **β 段階は日本語のみ**（DEC: Out of Scope）
- ただし以下を将来拡張可能に:
  - `next-intl` でメッセージ管理
  - 文字列をハードコードせず resource 化
  - 日付・通貨は Intl API で表示

## 7. ローディング状態

| 状態 | 表現 |
|---|---|
| 初期ロード | Skeleton + 骨組み |
| ボタン押下中 | Spinner + disabled |
| 楽観的更新 | useOptimistic で即時反映、失敗時ロールバック |
| 大量データ | infinite scroll + 部分表示 |

## 8. エラー状態

| 種別 | 表現 |
|---|---|
| バリデーション | フィールド下に赤テキスト |
| 通信失敗 | トースト + 再試行ボタン |
| 権限なし | 専用画面（"このページは閲覧できません"） |
| 404 | 専用ページ |
| 500 | 専用ページ + Sentry 報告 |

## 9. 空状態 (Empty State)

各リストには空状態を定義:
- イラスト or アイコン
- 主メッセージ "まだ予約がありません"
- 副メッセージ "スペースを検索して最初の予約を申し込んでください"
- CTA ボタン

## 10. ブランドアセット

- **ロゴ**: テキストロゴ + シンボル（[仮決定]、デザイナー作成待ち）
- **アイコン**: Lucide ベース、必要に応じてカスタム作成
- **イラスト**: undraw.co or 自社デザイナー（β は最小限）
- **写真**: スペース写真は施設ごとに、人物写真は利用しない（医療系の保守）

## 11. UI トーン

- **言葉遣い**: 丁寧語（です・ます調）、固すぎない
- **ボタンラベル**: 動詞主体（"予約する" "送信する"、"OK" は使わない）
- **エラーメッセージ**: 「○○が必要です」「○○してください」（ネガティブ表現を避ける）
- **成功メッセージ**: 「○○しました」「お疲れさまでした」
