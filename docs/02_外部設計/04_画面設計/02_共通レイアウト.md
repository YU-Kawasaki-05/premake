## 1. 認証ユーザー向けレイアウト（PC）

```
┌─────────────────────────────────────────────────────┐
│ 🅿 premake               [🔍] [🔔3] [👤 山田 ▾]     │ ← ヘッダ (固定)
├──────┬──────────────────────────────────────────────┤
│      │                                              │
│ ・🏠 │  ページコンテンツ                              │
│ ・📋 │                                              │
│ ・💰 │                                              │
│ ・💬 │                                              │
│      │                                              │
│      │                                              │
│ サイド │                                              │
│ ナビ  │                                              │
│      │                                              │
├──────┴──────────────────────────────────────────────┤
│ © premake / 利用規約 / プライバシー / 特商法           │ ← フッタ
└─────────────────────────────────────────────────────┘
```

### 1.1 ヘッダ要素
- ロゴ（クリックでロール別ダッシュボードへ）
- 中央: 大きい検索バー（看護師のみ。施設・指示医・運営は非表示）
- 右上: 通知ベル + 未読バッジ / アバター（メニュー: プロフィール / 設定 / ログアウト）

### 1.2 サイドナビ（ロール別）

#### 看護師
- ホーム
- 予約一覧
- スペースを探す
- 売上
- 公開ページ
- メッセージ
- 設定

#### 施設管理者
- ホーム
- 予約管理
- スペース管理
- 指示医
- 売上 / 入金
- メッセージ
- 設定

#### 指示医
- ホーム
- 指示書発行待ち
- 施術記録確認
- 担当予約
- 設定

#### 運営
- ダッシュボード
- ユーザー
- 審査キュー
- 取引監視
- 違反案件
- 返金処理
- CSV エクスポート
- 監査ログ
- お知らせ
- フィーチャーフラグ

#### 法人管理者
- ホーム（法人ダッシュボード）
- 配下施設
- 招待管理
- 法人プロフィール

### 1.3 フッタ要素
- 著作表示
- 利用規約 / プライバシー / 特商法 / 問い合わせリンク
- ステータスページリンク

## 5. 共通コンポーネント

### 5.1 Button (shadcn/ui Button 拡張)

| variant | 用途 |
|---|---|
| primary | 主要 CTA |
| secondary | 副 CTA |
| outline | キャンセル |
| ghost | テキストリンク風 |
| destructive | 削除・キャンセル |

### 5.2 Input / Select / Textarea
- ラベル必須
- バリデーションエラーは下に赤字
- 必須は `*` マーク

### 5.3 Modal / Dialog
- shadcn/ui Dialog
- 確認 / 詳細 / フォーム の 3 パターン

### 5.4 Toast (Sonner)
- 成功 / 失敗 / 情報 / 警告
- 自動消滅 5s
- アクション付き（"元に戻す" など）

### 5.5 Empty State

```
┌──────────────────────────┐
│      [📭 アイコン]        │
│                          │
│  まだ予約がありません       │
│                          │
│  スペースを検索して        │
│  最初の予約を申し込んで    │
│  ください                 │
│                          │
│  [スペースを探す →]       │
└──────────────────────────┘
```

### 5.6 Loading

```
[Skeleton ⌐■_■]   ← 初期ロード
[●Spinner]         ← ボタン押下中
```

### 5.7 Banner

ダッシュボード上部の警告/情報:

```
┌─────────────────────────────────────┐
│ ⚠ 看護師免許の審査中です（残り 2 営業日） │
└─────────────────────────────────────┘
```

色: 青 (info) / 黄 (warning) / 赤 (error) / 緑 (success)。

### 5.8 Status Badge

```
[●  公開中 ]   [●  下書き ]   [●  審査中 ]   [●  停止中 ]
緑              グレー         黄              赤
```

## 6. グローバル UX

### 6.1 ナビゲーション
- パンくず（深い階層のみ）
- ページ遷移時のスクロールトップ
- 戻るボタンの位置統一

### 6.2 確認モーダル

破壊的操作（キャンセル / 削除 / 凍結）は必ず確認モーダル:

```
┌─────────────────────────┐
│ 予約をキャンセルしますか？ │
│                         │
│ ・キャンセル料: 5,000 円  │
│ ・返金額: 5,000 円       │
│                         │
│ 理由（任意）:             │
│ [────────────────]      │
│                         │
│ [キャンセル] [確定する]   │
└─────────────────────────┘
```

### 6.3 楽観的更新（useOptimistic）

- 既読化 / 通知ステータス変更 等は楽観的に表示
- 失敗時はトーストで通知 + ロールバック
