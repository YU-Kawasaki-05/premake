## SCR-01: サインアップ（ロール選択）

**URL**: `/signup`
**関連 FR**: FR-01, FR-81 / **EP**: EP-A001, EP-A002, EP-A003 (招待付きの場合)

### ワイヤー

```
┌─────────────────────────────────────────────────┐
│  premake にアカウントを作成                       │
│                                                 │
│  ┌─────────────────────────────────────────┐   │
│  │  G  Google で続ける                      │   │
│  └─────────────────────────────────────────┘   │
│                                                 │
│  ──────────── または ────────────              │
│                                                 │
│  メールアドレス                                  │
│  [_______________________________________]     │
│                                                 │
│  パスワード（12 文字以上）                        │
│  [_______________________________________] 👁  │
│                                                 │
│  氏名（漢字） / 氏名（カナ）                      │
│  [_______________] [_______________]           │
│                                                 │
│  電話番号（+81）                                  │
│  [_______________________________________]     │
│                                                 │
│  ☐ 利用規約・プライバシーポリシーに同意します      │
│      (規約) (プライバシー)                        │
│                                                 │
│  ┌─────────────────────────────────────────┐   │
│  │           登録する                        │   │
│  └─────────────────────────────────────────┘   │
│                                                 │
│  既にアカウントをお持ちですか？ ログイン           │
└─────────────────────────────────────────────────┘
```

### 要素

| 要素 | 種別 | 必須 | バリデーション | 備考 |
|---|---|---|---|---|
| Google で続ける | Button | - | - | OAuth リダイレクト (EP-A002) |
| メール | Input(email) | ○ | RFC5322, 255 文字 | |
| パスワード | Input(password) | ○ | 12+, 大小英数記号 | 表示切替トグル |
| 氏名 | Input | ○ | 1-50 | |
| 氏名カナ | Input | ○ | 全角カナ | |
| 電話 | Input(tel) | ○ | E.164 | プレースホルダー: +81-90-1234-5678 |
| 規約同意 | Checkbox | ○ | true 必須 | |
| 登録 | Button | - | - | submit (EP-A001) |

### インタラクション

- メール入力時に重複チェック（debounced API）
- パスワード強度メーター表示
- 規約未同意時は登録ボタン disabled
- 成功 → SCR-02 へ
- 失敗 → エラー表示（下記）

### エラー状態

| エラー | 表示 |
|---|---|
| メール重複 | フィールド下「このメールアドレスは既に登録されています」 |
| パスワード強度不足 | 「12 文字以上、大小英数記号を含めてください」 |
| 規約未同意 | 「利用規約に同意してください」 |
| レート制限 | トースト「しばらくしてからお試しください」 |

### モバイル
- フォーム要素を縦積み
- Google ボタンは大きめ（タップしやすく）

## SCR-05: ログイン

**URL**: `/login`
**関連 FR**: FR-04 / **EP**: EP-A005

### ワイヤー

```
┌─────────────────────────────────────────────────┐
│  premake にログイン                              │
│                                                 │
│  [G  Google で続ける]                            │
│  ──── または ────                               │
│                                                 │
│  メールアドレス                                  │
│  [_______________________________________]     │
│                                                 │
│  パスワード         [パスワードを忘れた方]         │
│  [_______________________________________]     │
│                                                 │
│  ☐ ログイン状態を保持する（30 日）                │
│                                                 │
│  [        ログイン        ]                      │
│                                                 │
│  アカウントをお持ちでない方 → サインアップ         │
└─────────────────────────────────────────────────┘
```

### 要素

| 要素 | 種別 | 必須 | バリデーション |
|---|---|---|---|
| email | Input | ○ | - |
| password | Input | ○ | - |
| remember_me | Checkbox | × | - |

### エラー
- 失敗: 「メールアドレスまたはパスワードが正しくありません」（メール存在を漏らさない）
- ロック: 「アカウントがロックされています。15 分後に再試行してください」
- 凍結: 「アカウントが停止されています。サポートまでご連絡ください」

### MFA フロー
- 成功時 mfa_required=true なら **SCR-10 (MFA 検証)** へ遷移

## SCR-10: MFA 検証

**URL**: `/login/mfa`
**関連 FR**: FR-07 / **EP**: EP-A006

```
┌──────────────────────────────────────┐
│  二段階認証                           │
│                                      │
│  認証アプリで生成された 6 桁コードを   │
│  入力してください                      │
│                                      │
│      ┌─┬─┬─┬─┬─┬─┐                  │
│      │ │ │ │ │ │ │                  │
│      └─┴─┴─┴─┴─┴─┘                  │
│                                      │
│  [   検証する   ]                     │
│                                      │
│  バックアップコードを使う              │
└──────────────────────────────────────┘
```

- 6 桁数字入力（自動 focus 移動）
- 5 回失敗で一時セッション破棄 → SCR-05 戻り
- バックアップコード使用リンク

## SCR-11: 看護師免許アップロード

**URL**: `/onboarding/license`
**関連 FR**: FR-08 / **EP**: EP-A018

```
┌─────────────────────────────────────────────────┐
│  看護師免許の審査                                 │
│                                                 │
│  1/3 ステップ: 免許情報入力                        │
│                                                 │
│  ★ 籍登録番号                                   │
│  [______________]                                │
│                                                 │
│  ★ 籍登録年月日                                  │
│  [📅 ____/__/__]                                │
│                                                 │
│  ★ 本籍都道府県                                  │
│  [▾ 選択してください]                            │
│                                                 │
│             [次へ →]                            │
```

## その他の画面（簡易記述）

### SCR-02: サインアップ完了
- メッセージ: "確認メールを送信しました"
- 再送リンク (EP-A013)

### SCR-03: 招待受諾
- 招待トークンから施設名表示
- 通常サインアップと同フォーム + 役割明示
- token 失効時はエラー画面 + 招待元への問い合わせ導線

### SCR-04: 申請フォーム
- 法人 / 施設の選択
- 必須項目（医療機関名・開設届番号・担当者・申請理由）
- 申請後「審査開始」確認画面

### SCR-06 / SCR-07: パスワードリセット
- 06: メール入力フォーム → 確認メッセージ
- 07: 新パスワード + 確認入力（強度メーター付き）

### SCR-08: メール確認
- 自動検証（URL アクセスで完了）
- 失敗時: 再送ボタン

### SCR-09: MFA 設定
- 方式選択（TOTP / SMS）
- TOTP: QR コード表示 + 検証コード入力
- 完了時: バックアップコード 10 個を 1 度だけ表示（**ダウンロード推奨警告**）

### SCR-13: 医療機関開設届アップロード
- SCR-11 と同形式（開設届画像 + 担当者本人確認）

### SCR-14: 医師免許アップロード
- SCR-11 と同形式 + 医籍番号 + 専門医資格（任意）
