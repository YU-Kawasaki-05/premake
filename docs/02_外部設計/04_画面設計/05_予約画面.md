**URL**: `/search`
**関連 FR**: FR-19 / **EP**: EP-C001

```
│            │                                         │

```

### モバイル
- フィルタはボトムシート展開
- 結果は縦カード

### 検索結果カード要素
- サムネイル
- スペース名 + 施設名
- 平均評価 + レビュー数
- 推定料金（ユーザー指定日時で計算）
- 距離（住所指定時）
- 設備バッジ

### Empty State
- "条件に一致するスペースが見つかりませんでした"
- 「条件を緩和すると x 件見つかります」サジェスト
- "条件をリセット" ボタン

### バリデーション

| 条件 | エラー |
|---|---|
| カード未登録 | カード登録モーダル開く |

| 施術セッション間隔 < 1h | 「セッション間は 1 時間以上空けてください」 |

## その他簡易記述

### SCR-44: 予約変更
- 元情報表示 + 新セッション編集 + 変更理由
- 料金差分プレビュー
- 24h 以内なら警告

### SCR-45: 予約キャンセル
- ポリシー適用結果（返金額）プレビュー
- 確認モーダル

### SCR-47: 予約一覧（施設）
- 承認待ちが上部に集約
- フィルタ: 期間 / スペース / 看護師

### SCR-48: 予約詳細
- 全情報統合ビュー
- タイムライン（申込 → 承認 → 指示書発行 → 施術 → 完了）
- 関係者ごとに権限内のフィールド + アクション

### SCR-49: セッション詳細
- セッション内訳（カウンセリング / 施術）
- 各セッションのアクション（開始 / 完了 / スキップ）
- 関連指示書 / 施術記録へのリンク
