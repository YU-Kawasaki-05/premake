**URL**: `/doctor/prescriptions/{bid}/issue`
**関連 FR**: FR-29 / **EP**: EP-D003

│                                                       │

│                                                       │
│  ──────────────                                      │

### バリデーション

- 同意書 / 問診票が未確認 → 発行ボタン disabled
- TOTP コード必須（aal2 再認証）
- 確認チェックボックス必須

### 発行後

- PDF 生成中バナー
- 完了後「指示書を表示」ボタン

## その他

### SCR-52: 指示書 PDF 閲覧
- PDF iframe + 「ダウンロード」「QR 検証」ボタン
- 検証結果バッジ「✓ 電子署名検証 OK」

### SCR-53: 同意書テンプレート編集
- セクション drag-and-drop で並び替え
- 法令必須セクションは削除不可（disabled）
- バージョン履歴サイドパネル

### SCR-57: 施術記録検索
- フィルタ: 期間 / 看護師 / 医師 / 部位 / 異変ありのみ
- 一覧 → 詳細閲覧（PII マスキング適用）
