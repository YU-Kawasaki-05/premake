```
│  ┌────────────────────────────────┐                  │
│  │  明日 14 時に到着予定です          │                  │
│  └────────────────────────────────┘                  │
│  既読 13:45                                           │
│                                                       │
│                       施設管理者          11:02       │
│                       ┌────────────────────┐         │
│                       │ 承知しました。       │         │
│                       │ 駐車場をご利用ください │         │
│                       └────────────────────┘         │
│                                                       │
├──────────────────────────────────────────────────────┤
│  [📎] [_____________________________________] [送信] │
└──────────────────────────────────────────────────────┘
```

### 仕様

- リアルタイム配信（SSE / WebSocket）
- 添付画像最大 3 枚 × 5MB
- 既読管理
- メッセージ削除はソフトデリート（送信者のみ）
- 個人情報を含む可能性のある送信は警告ダイアログ
- 予約キャンセル後は閲覧のみ（送信不可）

### モバイル
- iMessage / LINE のような吹き出し UI
- スクロール時は上に履歴ロード（無限スクロール）
