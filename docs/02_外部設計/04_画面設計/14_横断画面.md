### フラグ編集モーダル

```
┌────────────────────────────────────────┐
│  フラグ編集 - show_review_beta          │
│                                        │
│  説明                                  │
│  [____________________________________] │
│                                        │
│  種別                                  │
│  ● release  ○ experiment              │
│  ○ kill     ○ config                  │
│                                        │
│  戦略                                  │
│  ● 全員  ○ x% rollout  ○ 特定ユーザー │
│                                        │
│  ☑ 有効化                              │
│                                        │
│  [ キャンセル ] [ 保存 (即時反映) ]     │
└────────────────────────────────────────┘
```

- aal2 必須
- 監査ログに変更履歴記録
- kill switch は赤色で目立つ表示
