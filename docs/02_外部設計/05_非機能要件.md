### 施策
- React Server Components 主体（クライアント JS 最小化）
- Next.js Image による画像最適化（WebP / AVIF 自動変換）
- フォントは next/font で self-host
- DB クエリは EXPLAIN ANALYZE で月次レビュー
- 検索は GIN インデックス + tsvector
- 距離検索は PostGIS GiST インデックス
- 集約 KPI はマテリアライズドビュー + バッチ更新

## 2. セキュリティ（NFR-SEC）

| ID | 要件 | 基準 | 優先度 |
|---|---|---|---|
| NFR-SEC-01 | TLS 1.3 強制 | HTTPS のみ | 必須 |
| NFR-SEC-02 | パスワードハッシュ | bcrypt cost 12+ | 必須 |
| NFR-SEC-03 | カード情報の自社非保持 | Stripe Elements 使用 (PCI DSS 回避) | 必須 |
| NFR-SEC-04 | PII / 医療データの at-rest 暗号化 | AES-256 (Storage) + pgcrypto (列) | 必須 |
| NFR-SEC-05 | データアクセスは RLS で保護 | 全テーブル ENABLE RLS | 必須 |
| NFR-SEC-06 | 監査ログの改ざん不可 | append-only + ハッシュチェーン | 必須 |
| NFR-SEC-07 | MFA 必須範囲 | ops 全員、その他は任意 | 必須 |
| NFR-SEC-08 | Service Role キーの非露出 | サーバー専用、CI チェック | 必須 |
| NFR-SEC-09 | レート制限 | 認証系 / SMS / 通報等 | 高 |
| NFR-SEC-10 | XSS / CSRF 対策 | Next.js 標準 + CSP ヘッダ | 必須 |
| NFR-SEC-11 | セキュリティヘッダ | HSTS / CSP / X-Content-Type-Options | 高 |
| NFR-SEC-12 | 依存ライブラリの脆弱性監視 | Dependabot 自動 | 高 |
| NFR-SEC-13 | ペネトレーションテスト | β 前 1 回、半年 1 回 | 中 |
| NFR-SEC-14 | 個人情報漏洩時の通知 | 1 時間以内に把握 + stakeholder 通知 | 必須 |
| NFR-SEC-15 | コンテンツセキュリティ | 画像・PDF のウイルススキャン（β後） | 中 |

### CSP ポリシー（参考）
```
Content-Security-Policy:
  default-src 'self';
  script-src 'self' https://js.stripe.com;
  connect-src 'self' https://*.supabase.co https://api.stripe.com;
  img-src 'self' data: https://*.supabase.co;
  frame-src https://js.stripe.com;
  object-src 'none';
  base-uri 'self';
```
