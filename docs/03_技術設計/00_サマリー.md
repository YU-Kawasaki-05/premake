# Phase 3 サマリー — premake / 技術設計

> Phase 1（要件）+ Phase 2（外部設計）を技術仕様として実装着手可能な状態に展開した。

---

## 1. 設計概要

**実装スタック（確定済 DEC-20〜29）**:
- Web: Next.js 15 App Router + Server Actions + TypeScript
- BaaS: Supabase（Postgres + Auth + Storage + Realtime + pg_cron）
- Hosting: Vercel Pro
- Payments: Stripe Connect Express
- Email / SMS: Resend + Twilio
- Monitoring: Sentry + Axiom
- UI: Tailwind + shadcn/ui + Lucide / RHF + zod / TanStack Query
- Jobs: Vercel Cron + pg_cron + 自前 worker_jobs（β コスト最小）

**開発体制**: User 1 人 + AI エージェント、12 週間で β 公開（DEC-07）。

**コア方針**:
- features 単位の機能凝集 + RSC ファースト
- 三層認可（Middleware → Server Action → RLS）
- 全ファイル `@implements FR-XX, AC-XX-YY` を必須化 → Phase 4 drift 検出
- β 期は外部 SaaS 追加なし、$0 で運用可能なジョブ基盤
- フィーチャーフラグ + 段階展開で安全にローンチ
