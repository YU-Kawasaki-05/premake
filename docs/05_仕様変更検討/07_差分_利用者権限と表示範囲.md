## 1. 何が変わるか（要約）

| 観点 | 現行 | 新方向性 |
|---|---|---|
| ロール定義（U-01〜U-06） | 維持 | 維持。**関係性のみ再定義** |

### 2.3 指示医 (U-03) の権限

**ほぼ維持**。役割は新方向性でも変わらず:
- 電子指示書発行（FR-29）
- 施術記録確認（FR-34）
- 担当予約一覧

追加:
- 業務委託で来る看護師に対する **指示書発行の連動性** を明示（誰の指示か）

### 2.4 運営 (U-04) の権限

維持 + 追加:
- **業務委託契約のモデレーション**: 不適切な契約条件の検出（搾取的料率等）
- **業務委託マッチングの監視**: 偽装請負・実質雇用と評価される兆候の検知
- **クリニックの請求書発行ワークフロー** (FR-NEW-11)
- **医療広告規制チェック支援**: 看護師の公開ページの不適切表現検出

### 2.5 利用客 (U-05) の権限

維持（ゲスト予約・OTP）、ただし:
- 同意先が **クリニック X** であることの明示
- 予約照会（FR-74）で「医療機関」「担当看護師」「サポート窓口」をクリアに表示
- 自由診療契約の主体が **クリニック** であることの明示

### 2.6 法人管理者 (U-06) の権限

維持 + 追加:
- 配下クリニックの **業務委託契約一覧の法人横断ビュー**
- 配下クリニックの **業務委託費合計・看護師数** の集計
- 法人レベルでの **業務委託標準条件** のテンプレート設定（任意）

## 3. 公開ページ・表示範囲：医療広告規制への対応

### 3.1 医療広告規制の概要

[厚労省「医療広告ガイドライン」] に基づく:
- 病院・診療所が広告できる事項は **医療法 第 6 条の 5** で限定列挙
- **限定解除要件** を満たすと比較・体験談・症例写真等の表示可
- 限定解除要件は **問い合わせ先・公開ページの責任主体** が明示されているか等

### 3.2 看護師の公開ページ：限定解除要件への対応

公開ページ (FR-69) で表示する内容ごとに、医療広告ガイドラインの整理:

| 表示項目 | 現行 | 新方向性 / 対応 |
|---|---|---|
| 看護師の氏名・経歴 | ○ | 維持。「業務委託契約に基づく担当看護師」と明示 |
| プロフィール写真 | ○ | 維持 |
| **症例写真（ビフォーアフター）** | △ | **限定解除要件を満たす + クリニック責任のもとで掲載** |
| **レビュー / 口コミ** | ○ | **慎重**。医療広告規制でレビューは規制対象、限定解除要件 + クリニック責任明示 |
| 料金表示 | ○ | 維持。「クリニックの自由診療料金」と明示 |
| 「premake 認定」「医師不要」等 | × | **禁止** |
| クリニック名・住所・連絡先 | △ | **必須** |
| 医師の関与 | △ | **明示**「医師の判断・指示下」 |

### 3.3 限定解除要件の明示

公開ページに以下を表示することで限定解除を満たす:

```
【医療提供主体】
山田クリニック（東京都新宿区...）
電話: 03-XXXX-XXXX
※ お問い合わせ・苦情はこちらまで

【医師の関与】
施術可否の判断、医師指示、緊急時対応は山田クリニックの医師が行います

【自由診療】
本施術は保険適用外の自由診療です
費用、リスク、副作用は事前にご確認ください

【症例写真・レビューについて】
本ページに掲載の症例写真・レビューは、施術を受けた個人の感想であり、
効果には個人差があります。
```

### 3.4 看護師プロフィールの記載範囲

維持できる:
- 看護師免許保有・経験年数
- 専門領域・研修履歴
- 自己紹介
- 提供メニュー

調整が必要:
- 「premake 認定」等のラベル → 削除
- 「資格情報・対応可能範囲」のみ表示
- 第三者評価・ランキング表示 → 削除候補（医療広告規制で慎重）

## 5. 思考の足跡

### 5.1 検討した別案

#### 別案 X: 看護師の権限を大幅縮小（実質オペレータ化）
- 不採用理由: 業務委託モデルでは看護師は独立事業者。権限縮小は業務委託の実態と矛盾

#### 別案 Y: 公開ページを完全廃止
- 不採用理由 [User 確認: 2026-05-18]: 看護師の公開ページからの予約フローは維持

### 5.2 残された問い

- **レビュー機能の公開廃止 vs 限定解除での維持** の判断 → 弁護士確認
- **看護師のプロフィール写真** の医療広告規制上の扱い
- **法人横断の業務委託標準料率** が独占禁止法上問題ないか
- 看護師の **複数クリニック対応** UI で誤認が起きないか（どのクリニックでの施術か）

### 5.3 弁護士に確認したい論点

1. 看護師の公開ページに **クリニック名・医師関与** を表示することで医療広告規制の限定解除要件を満たすか
2. **レビュー・症例写真** の表示可否、限定解除の具体条件
3. **看護師のプロフィール写真** の規制適用
4. 看護師の **複数クリニック契約** で公開ページにメニューごとに別クリニックを表示することの法的整理
