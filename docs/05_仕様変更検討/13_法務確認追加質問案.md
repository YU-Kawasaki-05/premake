## 2. 本ブランチ分析で浮上した追加質問

### Q-NEW-01: 業務委託マッチング機能の許認可

**質問**: premake が看護師とクリニックを **マッチング** する機能（看護師が候補クリニックを検索 → 業務委託契約を申込）は、以下のいずれに該当するか:

- a) 職業紹介事業（許可必要）
- b) 募集情報等提供事業（届出可能性）
- c) 単なる情報提供（許認可不要）

**背景**: 法務確認資料 §5.1 質問 3 で言及されているが、業務委託契約のマッチングが「雇用関係成立のあっせん」と評価される懸念。

**判定軸（参考）**:
- 雇用関係ではなく **業務委託契約** のマッチングであること
- premake は **契約条件を提示しない**（クリニック⇔看護師が個別交渉）
- 報酬の徴収方法（premake はクリニックから月次利用料を徴収）

**実装への影響**: 該当する場合、届出 or 許可取得が必要。マッチング機能 (FR-NEW-01〜04) の実装可否に直結。

### Q-NEW-02: 包括業務委託 + 案件アサイン モデルの偽装請負評価

**質問**: 看護師がクリニックと **1 度の包括業務委託契約**を締結し、その後 premake 経由で予約発生のたびに「アサイン」される運用は、偽装請負・実質雇用と評価されるリスクがあるか?

**システム設計への対応**:
- 看護師の **独立性** を担保する設計（時間管理しない、業務指揮の独立性条項）
- 看護師の **複数クリニック契約** を可視化（独立事業者の証拠）
- **業務上の指示** と **医学的指示** を契約・運用で明確に区別

**判定軸**: 厚労省「労働者派遣事業と請負により行われる事業との区分に関する基準」(37 号告示)

### Q-NEW-03: クリニックが Stripe で直接受領するモデルの特商法表記

**質問**: 患者が **クリニックの Stripe Connect Account に直接決済** する場合、特定商取引法上の **販売事業者** はクリニック単独か、それとも premake も併記するか?

**現行設計**: クリニックを販売事業者として表示、premake は予約・決済支援として明示。

**確認したい点**:
- premake のサイト上の特商法表記の **書き分け**（クリニック側 vs premake 側）
- 看護師の公開ページに **クリニックの特商法表記** を直接埋め込むことの可否

### Q-NEW-04: premake の月次プラットフォーム利用料の課税・会計

**質問**: premake がクリニックに対して月次で請求する **プラットフォーム利用料** の税務上の扱いと、課税仕入の控除可否は?

**仮整理**:
- premake → クリニックへの **役務提供** として消費税課税
- クリニックは課税仕入として控除可
- インボイス対応（premake のインボイス登録番号を必須化）

### Q-NEW-05: 看護師個人事業主への源泉徴収

**質問**: クリニックが看護師（個人事業主）に **業務委託費** を支払う際、源泉徴収義務はあるか? あるとすれば税率は?

**現行整理**:
- 看護師の業務委託費が「**報酬・料金**」(所得税法 第 204 条) に該当する可能性
- 該当する場合、10.21% の源泉徴収義務

**実装への影響**: 業務委託費精算明細 (FR-NEW-13) に源泉控除計算を組み込む必要

### Q-NEW-06: 看護師の複数クリニック契約と競業避止

**質問**: クリニック A と業務委託契約中の看護師が、競合クリニック B とも契約することを禁止する条項は法的に有効か?

**ユーザー方針 [User 確認: 2026-05-18]**: 制限なし
**ただし**: クリニック側が任意で **競業避止条項** を入れたい場合の可否

**判定軸**:
- 看護師の **職業選択の自由**（憲法 22 条）
- 競業避止が **合理的範囲**（期間・地域・対価）であるか

---

### Q-NEW-07: 業務委託契約解除時の既存予約の扱い

**質問**: クリニック⇔看護師の業務委託契約が解除された場合、既に成立している **患者の予約** をどう扱うべきか?

**3 つの選択肢**:
- a) 全て履行（解除予告期間中に施術完了させる）
- b) 全てキャンセル + 患者全額返金
- c) 他の契約看護師に振替

**実装への影響**: FR-NEW-38, 39 の設計に直結。

### Q-NEW-08: 看護師の公開ページに掲載する症例写真・レビューの限定解除要件

**質問**: 看護師の公開ページ (FR-69) に掲載する以下のコンテンツについて、医療広告ガイドラインの限定解除要件を満たすには何が必要か?

- 症例写真（ビフォーアフター）
- 利用客のレビュー
- 看護師のプロフィール写真
- 「経験 X 年」「実績 N 件」等の数値表示

**前提**: 看護師の公開ページに「医療提供主体: クリニック X」「医師の判断・指示下」を明示する。

### Q-NEW-09: 患者の事前決済のクリニック受領の特商法・キャンセル規定

**質問**: 患者が premake 経由で **施術日前** に決済する場合（事前決済 FR-39）、特商法上の解約・返金規定は誰が定めるか?

**整理**:
- 販売事業者: **クリニック**
- 解約・返金規定: クリニックの自由診療契約に基づく
- premake のキャンセルポリシー (FR-41) は **デフォルト値の提示** であり、クリニックが上書き可能

### Q-NEW-10: 電子契約（Cloud Sign 等）の業務委託契約への有効性

**質問**: Cloud Sign 等の電子契約サービスで締結する業務委託契約は、**民法・労働法・税法** 上、紙の契約と同等の有効性を持つか?

**追加確認**:

- 電子署名法の **本人性・非改ざん性** の担保

### Q-NEW-11: 医療情報安全管理ガイドライン §6.4 の委託先要件

**質問**: premake が **医療情報を保管する委託先** として、厚労省「医療情報システムの安全管理に関するガイドライン 第 6.0 版」§6.4 を満たすには何が必要か?

**現状の対応**:
- RLS + 監査ログ + ハッシュチェーン + 月次アクセスレポート
- Supabase / Vercel 等の SOC 2 / ISO 27001 利用

**追加確認**:
- 委託契約での **安全管理措置の明示**
- **再委託**（Supabase 等）の取扱
- インシデント発生時の **委託元（クリニック）への通知義務**

### Q-NEW-13: 業務委託費の独占禁止法・優越的地位濫用

**質問**: premake が **クリニック最低取り分** を強制する、または **標準料率** を提示することは、独禁法上の「優越的地位濫用」と評価されるリスクがあるか?

**前提**: User 方針: premake が推奨料率提示、クリニック⇔看護師の相談で確定。

### Q-NEW-15: 緊急時対応 - 医師がその場にいない場合の責任

**質問**: 業務委託モデルでは **医師が常時クリニックに在駐していない可能性** がある。施術中の急変時に医師不在の場合、誰が責任を負うか?

**システム設計**:
- 緊急時連絡先テンプレート (FR-NEW-34)
- 救急搬送先事前登録 (FR-NEW-36)

**法務確認**:
- **医師の即応性要件**（オンライン診療 / 院内滞在 / オンコール）
- 緊急時対応の **業務委託契約での明示**

### Q-NEW-16: 看護師の保険加入の必須化

**質問**: 看護師の **賠償責任保険** 未加入で施術中に医療事故が発生した場合、責任は誰に及ぶか? premake はシステム上 **未加入者の予約をブロック** すべきか?

**確認**:

### Q-NEW-19: 患者の自由診療契約・同意書のクリニック契約化

**質問**: 患者の同意書を **クリニックの自由診療契約の一部** として再構築する場合、premake が **テンプレートを提供** することは法的に問題ないか?

**整理**:
- premake は **テンプレート提供**、契約主体はクリニック
- 同意書の **電子的保存** の有効性

**背景**: 令和 4 年改正職安法で募集情報等提供事業の届出制度が新設。雇用関係ではないため該当しない可能性が高いが要確認。

## 5. 思考の足跡

### 5.1 質問の構築方法

- 法務確認資料 v0.9 を **網羅** （re-emphasis）
- 本ブランチの分析で浮上した **新規論点** を追加
- 各質問に **背景・判定軸・実装への影響** を併記し、弁護士の判断材料を最大化

### 5.2 想定する弁護士相談の流れ

- **第 1 回（30 分）**: 最優先 4 件 + 法務確認資料 v0.9 §5.1 質問 1〜8 の概要回答
- **第 2 回（60 分）**: 高優先 + 残りの v0.9 §5.1 + 業務委託契約書の具体的レビュー
- **継続契約（月次）**: 運用中の論点を月次で相談

- 弁護士の **医療法務専門性** が最重要、紹介依頼を v0.9 §8.5 に追加済み
- 弁護士相談の **記録・議事録** をどう構造化して保存するか
