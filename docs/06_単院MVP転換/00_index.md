## 結論サマリー(3行)

1. **旧仕様(Phase 1-3 = マッチングプラットフォーム)は弁護士見解(2026-06-07)と 6/28 ピボット検討により土台が失効**。88 機能のうちマッチング・審査・手数料按分系は凍結し、単院向け予約管理システムとして再スコープする。
2. **単院・院内ツール化により法務リスクは激減**(職業紹介/派遣/募集情報等提供に非該当、患者→クリニック直接決済)。残る論点は医療広告(公開予約ページ)と医療情報の安全管理のみ。
3. **器は業種非依存に設計**(マルチテナント + 予約対象メニューの抽象化)し、6/28 検討の本命 B(メーカー試験)/ M(既存客クロスセル)/ 治験にも同じ器を流用できる形にする。
