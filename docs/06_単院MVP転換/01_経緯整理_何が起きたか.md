## 2. 弁護士フィードバック(6/7)の要点 — 設計制約として

1. アートメイク = 医行為。医師が行うのでなければ医師法 17 条違反(当局の一貫した見解)。
2. 「医師の指示により看護師が施術」で手堅く許容されるのは、**医療機関が雇用している看護師とともに医師が施術する形**(他の内科・皮膚科と同様)という解釈が一番堅い。
3. 医師の指示下の業務 = 指揮命令下 = **雇用契約であり、業務委託とは実態として矛盾**。
4. Web プラットフォームを通じた業務委託看護師の派遣スキームは、**スキーム自体が禁止される可能性を内包**。
5. 看護師個人の集客(インスタ等)は相当疑問。看護師が患者から直接相談を受けることも無資格医行為の可能性。
6. 医療機器(マシン・針)は医師が管理すべきもの。看護師の持ち込み複数院利用は不可。
7. 事前診察 + 指示書・カルテ作成は当然必要。**施術中は医師が常駐し緊急対応できる体制**まで必要。
8. 患者 → premake への支払いフロー(募集情報等提供スキームでの報酬受領)は職業安定法改正(法 43 条の 3)により**認められない可能性**。

## 3. 6/28 ピボット検討の要点 — 事業戦略として

- 賭ける資産は「空き部屋」ではなく **「医師の信頼・時間」「既存の美容顧客」**。
- **アートメイクは "売り物" ではなく "入口(コネクション)" 兼 "第一弾"**。
- アートメイクを売り物にもするなら成立しうる形は一つ: **「クリニック前面・主体は医師・クリニック内での看護師指名・症例は限定解除準拠」**。
- この器は業種非依存であり、本命 **B(メーカー臨床評価/モニター試験/研修会場)・M(既存美容顧客へのクロスセル)・美容系治験** にそのまま流用できる。
- 純粋な業務管理 SaaS(予約+記録+決済)は競合が密(medical force / b4a / ACUSIS)で勝てない → **SaaS 単体をビジネスにはしない**。
- 「やるな」リスト: 空き部屋前提のマーケットプレイス構築、**アートメイク前提の DB/API 実装**(売り物確定前は投機)、施術者の大量募集、LP 制作。
- 検証プラン: ①遊休量実測 ②医師に「何で埋めたいか」を聞く ③コンシェルジュ MVP ④縁故ゼロ 3〜5 院への一般化テスト・有償 pilot 1 院。
