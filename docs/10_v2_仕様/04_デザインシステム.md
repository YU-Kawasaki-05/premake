# premake v2 デザインシステム

> DEC-06(UX・デザイン品質最優先)を単院 MVP でも貫く。
> 禁止: AI 生成 UI の典型(紫グラデーション、絵文字見出し、意味のないカード羅列、過剰な影と角丸、`bg-blue-500` 的な Tailwind 標準色の無思考な使用)。
> 目標: 「受付が紙の台帳より速いと感じる業務ツール」×「患者が信頼を感じる上質なクリニックページ」。

## 1. 二つの顔

| | 院内アプリ(app) | 公開ページ(public) |
|---|---|---|
| 参照品質 | Linear / Notion Calendar / 医療系業務ツールの良品 | 上質な美容クリニック・ホテルのサイト |
| 優先 | 情報密度・視認性・操作速度 | 余白・信頼感・読みやすさ |
| ベースサイズ | 14px(数値・台帳は 13px 可) | 16px |
| 角丸 | 6px(控えめ) | 2〜4px(シャープに上品) |
| 影 | 原則なし(ボーダー基調)。オーバーレイのみ薄い影 | なし。区切りは余白と細罫 |

## 2. カラー(CSS 変数 / Tailwind @theme)

```css
/* ニュートラル: stone 系(温かみのあるグレー)をベースに採用 */
--color-ink:        #1C1917;  /* 主要テキスト(墨) */
--color-ink-soft:   #57534E;  /* 副次テキスト */
--color-ink-faint:  #A8A29E;  /* 補助・placeholder */
--color-paper:      #FAFAF8;  /* 公開ページ背景(生成り) */
--color-surface:    #FFFFFF;
--color-line:       #E7E5E4;  /* 罫線 */
--color-line-soft:  #F0EFED;

/* プライマリ: 深いモスグリーン(医療の清潔感 × 美容の上品さ)*/
--color-primary:        #1D5C4D;
--color-primary-strong: #164539;
--color-primary-soft:   #EAF2EF;  /* 選択面・ホバー面 */

/* 公開ページのアクセント(控えめなブロンズ。多用しない)*/
--color-accent: #96794F;
```

| ステータス | 色(text/border) | 面(bg) | アイコン |

| requested 承認待ち | #A16207 | #FDF6E3 | ◐ clock |
| confirmed 確定 | #1D5C4D | #EAF2EF | ● check |

## 4. コンポーネント方針

- **shadcn/ui をベースに、上記トークンへ全面的に再テーマ**(標準の slate/zinc のまま使わない)。
- Button: primary(深緑・白字)/ secondary(白・罫線)/ ghost / destructive。高さ app=34px, public=48px(タップ)。
- フォーム: ラベル上置き 12.5px/500、エラーは入力下に赤 12.5px + アイコン。必須は「必須」バッジ(※アスタリスク不可 — 高齢患者にも分かる表記)。
- 日時表示: `7/12(金) 13:00–15:30` 形式で統一(曜日必須。tabular-nums)。
- 空状態: 挿絵に頼らず、次のアクションへの 1 文+ボタン。
- トースト: 右下、成功は静かに(2.5s)、失敗は手動クローズ+リトライ導線。
- ローディング: スケルトン(台帳はレーン構造のまま骨組み表示)。スピナー多用禁止。

## 5. アクセシビリティ

- コントラスト: 本文 4.5:1 以上(ink/paper 検証済み)。ステータスは色+形+文字。
- フォーカスリング: 2px primary、`:focus-visible` のみ。台帳はキーボード操作(矢印移動・Enter 詳細)。
- 公開フォーム: label/for、autocomplete(name, tel, email)、inputmode、エラーの aria-describedby。

## 6. 実装形態

- `src/styles/tokens.css` に CSS 変数 → Tailwind v4 `@theme` で参照。ダークモードは**院内アプリのみ** Phase 2(公開ページはライト固定)。
- `src/components/ui/`(shadcn 再テーマ)+ `src/components/app/`(台帳等の業務コンポーネント)+ `src/components/public/`(公開ページ)。
