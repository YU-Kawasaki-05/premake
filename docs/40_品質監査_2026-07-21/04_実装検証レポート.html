3. ツール出力汚染の記録(次セッションへの警告)

  • 同一ファイルの wc -c が「11187バイト」↔「空(0)」を交互に返す
  • 同一の pnpm lint / git rev-parse HEAD が異なる値を交互に返す(実在しないコミット 1e05920 / c1a4f9e / 88178f9 が「観測」された)
  • サブエージェント / Workflow の「完了報告」が実体なしに届いた(★2A/★2B/★2core/★3/敵対検証Workflow)。git status 変更ゼロ・transcript 不在・TaskStop "No task found" で検知
  • lint「33件 noExplicitAny」は幻(biome JSON レポータの真の診断は format/organizeImports の整形系のみ)
教訓: 単発のツール出力・エージェント完了報告を信用しない。実装の実在は git status + ファイル内容マーカーの直接検査で確認してから次工程に進むこと。
誤魔化しの不在(物証): 差分検査で biome-ignore / @ts-ignore / eslint-disable / : any の追加、biome.json 改変、it.skip/only 追加はすべて 0 件。lint 解消は import 並び順の正規修正のみ。
