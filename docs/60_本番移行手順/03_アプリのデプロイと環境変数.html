STEP 3 デプロイと環境変数

アプリを Vercel でインターネットに公開し、動作に必要な環境変数(設定値)を登録します。安全のための CRON_SECRET も設定します。

目安 約40分クリニック担当者

この STEP でやること

アプリ本体を Vercel でインターネットに公開(デプロイ)し、動作に必要な環境変数(設定値)を登録します。ここまで来ると、ブラウザからアプリのログイン画面が開けるようになります。

3-1. Vercel にアプリを公開する クリニック担当者

  1. Vercel に登録・ログインvercel.com でアカウント作成。アプリのプログラムがある GitHub アカウントで登録すると連携が簡単です。
  2. プロジェクトを取り込む(Import)「Add New… → Project」から、アプリのリポジトリ(開発担当者に確認)を選び「Import」。
  3. 設定はそのままでよいFramework は自動で「Next.js」と認識されます。ビルド設定は既定のままで構いません(この段階では「Deploy」を押す前に、次の 3-2 の環境変数を先に入れると手戻りが減ります)。

☞先に環境変数を入れるのがコツ

アプリは環境変数がそろって初めて正しく動きます。3-2 の環境変数を登録してから「Deploy」を押すと、1回で正しく公開できます。もし先に公開してしまっても、3-2 を登録後に「再デプロイ(Redeploy)」すれば直ります。

3-2. 環境変数(設定値)を登録する クリニック担当者

Vercel のプロジェクト → 「Settings」→「Environment Variables」で、下の表の値を1つずつ登録します。対象環境は Production(本番) にチェックを入れてください。「名前(Key)」は一字一句そのまま正確に入力します。

名前(Key)役割(やさしく)入れる値・取得先
NEXT_PUBLIC_SUPABASE_URLデータベースの住所STEP 2 で控えた Project URL
NEXT_PUBLIC_SUPABASE_ANON_KEY一般アクセス用の鍵STEP 2 で控えた anon public キー
SUPABASE_SERVICE_ROLE_KEY全権の秘密鍵(サーバー内部でのみ使用)STEP 2 で控えた service_role キー。秘密
APP_URLアプリの本番 URL。メールや招待リンクの生成に使うこのアプリの本番 URL(例 https://your-clinic.vercel.app)
RESEND_API_KEYメール送信の鍵STEP 4 で取得(この段階では空でも公開可。メールは STEP 4 完了後に有効化)
CRON_SECRET定期実行を守る合言葉下の 3-3 で作る強いランダム文字列

⚠NEXT_PUBLIC_ で始まる2つは「公開後」に変えたら再デプロイが必要

NEXT_PUBLIC_... の2つの値は、アプリを組み立てる時(ビルド時)に埋め込まれます。後から変更した場合は、Vercel の「Deployments」→ 最新 → 「Redeploy」で作り直してください。

3-3. CRON_SECRET を強いランダム値にする(重要な安全対策)

CRON_SECRET は、前日リマインダーなどの定期実行を『関係者以外が叩けない』ようにする合言葉です。この値は必ず推測できない強いランダム文字列にしてください。

⚠なぜ必須か(SEC-01)

この合言葉を設定しないと、本番では定期実行の入口が拒否(fail-closed)され、リマインダー等が動きません。逆に弱い値や空だと、第三者が定期実行を勝手に呼び出し、大量のメール送信や不正な処理を誘発できてしまいます。必ず強い値を設定してください。

ⓘうれしい仕組み

Vercel は、CRON_SECRET を環境変数に登録しておくと、定期実行のときに自動でこの合言葉を付けてアプリを呼び出します。つまり値を登録するだけで、正規の定期実行は通り、部外者は弾かれる状態になります。

3-4. APP_URL を本番 URL にする理由

APP_URL は、メール内のリンクや、スタッフ招待リンクを組み立てる時の土台の URL です。ここを本番 URL にしておかないと、初期値の http://localhost:3000(手元のパソコン)を指してしまい、患者やスタッフが受け取ったリンクを開けません。必ず本番 URL を設定してください。

3-5. デプロイして動作を確認する

  1. Deploy(または Redeploy)環境変数を登録したら公開します。数分でビルドが終わります。
  2. 本番 URL を開く発行された URL(例 https://your-clinic.vercel.app)をブラウザで開きます。
  3. ログイン画面を確認URL の末尾に /login を付けてログイン画面が表示されれば、公開は成功です。STEP 2 で作った ops アカウントでログインを試せます(ログイン後は /ops でクリニック管理画面へ)。

☞任意: 応答を速くする

Vercel のプロジェクト設定で、サーバー処理の地域(Function Region)を Tokyo(hnd1) にすると、東京の Supabase との通信が速くなります(必須ではありません)。
