STEP 6 初期設定とデータ登録

院長ログインから看護師の招待、メニュー・部屋・担当・施術枠の登録まで。看護師が予約を始められる状態にします。

目安 約60分クリニック担当者

この STEP でやること

ここからはアプリの画面をクリックして進める作業です。院長ログイン → 看護師の招待 → メニュー・部屋・担当・施術枠の登録まで行い、看護師が予約を作り始められる状態にします。

ⓘ全体の流れ

① 運営(ops)がクリニックと院長を作る → ② 院長がログインしてクリニック情報を設定 → ③ 院長が看護師を招待 → ④ 部屋・メニュー・担当・施術枠を登録 → ⑤ 看護師が予約を作れる。

6-1. 運営(ops)がクリニックと院長を作成する

  1. ops でログイン本番 URL の /login から、STEP 2 で作った ops アカウントでログインし、/ops を開きます。
  2. 「クリニックを追加」次の3つを入力します。
    ・クリニック名(例: 〇〇クリニック)
    ・slug(スラッグ)= URL に使う短い英字名(例 sakura → アプリ内 URL が /sakura になる)
    ・院長のメールアドレス(この人が最初の管理者=owner になります)
  3. 表示された招待リンクを院長に渡す作成すると招待リンク(URL)が画面に出ます。これを院長に安全な方法で伝えます(現状メールは自動送信されないため、手渡し/チャット等で共有します)。

⚠slug のルール

slug は英小文字・数字・ハイフンのみ(2〜31文字)。ops login api などの予約語は使えません。一度決めると URL になるため、短く分かりやすい名前にしましょう。

⚠招待リンクが localhost になっていたら

招待リンクの土台は環境変数 APP_URL です。リンクが localhost で始まっている場合、STEP 3 の APP_URL が本番 URL になっていません。設定し直して再デプロイしてください。また招待リンクの有効期限は7日間です。

6-2. 院長(owner)が参加してクリニック情報を設定する

  1. 招待リンクを開く院長が受け取ったリンクを開き、お名前とパスワード(8文字以上)を設定します。設定するとそのままログインし、予約台帳の画面に入ります。
  2. クリニック情報を入力画面の「設定」で、院長名・住所・電話番号・郵便番号・連絡先メールなどを登録します。
  3. 診療時間を設定曜日ごとの診療時間(開始・終了)を登録します。
  4. 公開予約は『オフ』のまま「公開予約」は初期状態でオフです。今回は院内運用のみなのでオフのままにしておきます(承認モードは manual のままで問題ありません)。公開を検討する際は 未対応事項 を必ず確認してください。

6-3. 院長が看護師(スタッフ)を招待する

  1. スタッフ管理を開く画面のナビゲーションから「スタッフ」を開きます。
  2. 招待する看護師のメールアドレスと役割(スタッフ)、雇用形態(常勤/業務委託)を指定して招待します。表示された招待リンクを各看護師に渡します。
  3. 看護師が参加看護師が招待リンクを開き、名前とパスワードを設定すると、予約台帳・施術枠・患者の画面が使えるようになります。

ⓘ役割の違い(かんたん)

owner(院長)=料金・メニュー・スタッフなど全部を設定できる。staff(看護師)=予約台帳・施術枠・患者の日常業務ができる(設定変更はできない)。

6-4. 予約に必要なデータを登録する(院長)

看護師が予約を作るには、あらかじめ次を登録しておく必要があります。上から順に進めると迷いません。

  1. 部屋を登録「部屋」画面で、施術室(例: 施術室1・施術室2)を登録します。
  2. メニューを登録「メニュー」画面で、カテゴリ(例: アートメイク)と施術メニューを登録します。各メニューには『セッション構成』(施術の工程と所要時間)を設定します。例: カウンセリング30分 → 施術120分(準備・清掃のバッファ15分)。料金や公開/非公開もここで設定します。
  3. 担当(できる人)を割り当てる「担当マトリクス」で、どの看護師がどのメニューを担当できるかを設定します。予約作成時の担当候補になります。
  4. 施術枠を登録「施術枠」画面で、看護師・部屋ごとの受付可能な時間帯(open 枠)を登録します。

ⓘ施術枠について(仕様上の注意)

院内予約(看護師が台帳に入れる予約)は、現状施術枠が無くても作成できます(枠外でも警告なく作れます)。施術枠は主に「施術枠表示」や将来の公開予約のためのものです。とはいえ、運用の見通しをよくするため登録を推奨します。

6-5. 看護師が予約を作れることを確認する

ここまでで準備は完了です。看護師がログインし、予約台帳から予約を作れます。中核の流れは次のとおりです(くわしい確認は STEP 7)。

操作結果
予約台帳で「予約を作成」→ 患者を検索 or 新規登録 → メニュー・担当・部屋・日時を指定確定(confirmed)予約が作成される。患者にメール(email があれば)
来院当日、予約を「受付(チェックイン)」状態が checked_in になる
施術が終わったら「完了」状態が done になる
取りやめのときは「キャンセル」(理由を入力)状態が cancelled になり、枠が空きに戻る

☞予約の『変更(日時・担当の付け替え)』は現状ありません

予約内容を変えたいときは、いったんキャンセルして作り直す運用になります(リスケ機能は今回未実装。未対応事項参照)。
