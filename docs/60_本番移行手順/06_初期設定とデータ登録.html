STEP 6 初期設定とデータ登録

院長ログインからスタッフの招待、部屋・メニュー・担当・施術枠の登録、そして患者向け公開 Web 予約の公開まで。院内と Web の両方から予約を受け付けられる状態にします。

目安 約90分クリニック担当者

この STEP でやること

ここからはアプリの画面をクリックして進める作業です。院長でログインし、スタッフを招待し、予約に必要なデータを登録して、最後に患者向けの公開 Web 予約をオンにするまでを行います。

ⓘ全体の流れ

① 運営(ops)がクリニックと院長を作る → ② 院長がログインしてクリニック情報を設定(メールアドレスが院内へのお知らせの宛先になります) → ③ 院長がスタッフを招待 → ④ 部屋・メニュー・担当・施術枠を登録 → ⑤ 公開 Web 予約をオンにする → ⑥ 日常の操作(予約の変更・患者への紐付け)を覚える。

⚠この版から「公開 Web 予約を使う」前提に変わりました

以前の版では「公開予約はオフのまま(院内運用のみ)」を推奨していましたが、運用方針の決定により患者向けの Web 予約をオンにして運用します。確定のしかたは「院内で確認してから確定」(手動承認)を推奨します。

そのため、6-4 の「担当設定」と「施術枠」の登録が今までより重要になりました。ここを飛ばすと、患者側の画面に空き時間が 1 件も出ません。

6-1. 運営(ops)がクリニックと院長を作成する

  1. ops でログイン本番 URL の /login から、STEP 2 で作った ops アカウントでログインし、/ops を開きます。
  2. 「クリニックを追加」次の3つを入力します。
    ・クリニック名(例: 〇〇クリニック)
    ・slug(スラッグ)= URL に使う短い英字名(例 sakura → アプリ内 URL が /sakura になる)
    ・院長のメールアドレス(この人が最初の管理者=owner になります)
  3. 表示された招待リンクを院長に渡す作成すると招待リンク(URL)が画面に出ます。これを院長に安全な方法で伝えます(現状メールは自動送信されないため、手渡し/チャット等で共有します)。

⚠slug のルール

slug は英小文字・数字・ハイフンのみ(2〜31文字)。ops login api などの予約語は使えません。一度決めると URL になるため、短く分かりやすい名前にしましょう。

⚠招待リンクが localhost になっていたら

招待リンクの土台は環境変数 APP_URL です。リンクが localhost で始まっている場合、STEP 3 の APP_URL が本番 URL になっていません。設定し直して再デプロイしてください。また招待リンクの有効期限は7日間です。

6-2. 院長(owner)が参加してクリニック情報を設定する

  1. 招待リンクを開く院長が受け取ったリンクを開き、お名前とパスワード(8文字以上)を設定します。設定するとそのままログインし、予約台帳の画面に入ります。
  2. 「クリニック設定」の『基本情報』を入力左のナビゲーション(スマートフォンでは上部のメニュー)から「クリニック設定」を開き、いちばん上の「基本情報」に クリニック名 / 院長名 / 郵便番号 / 住所 / 電話番号 / メールアドレス を入力して「保存」を押します。
  3. 「営業時間」を入力同じ画面の「営業時間」で、曜日ごとの開始・終了時刻を登録します。ここで入れた時間が、患者向けの公開ページに「診療時間」として表示されます。
  4. 公開予約の設定はまだ触らない同じ画面のいちばん下に「オンライン予約」がありますが、ここは 6-4 のデータ登録が終わってから設定します(6-5)。先にオンにすると、空き時間が 1 件も無い公開ページが患者に見えてしまいます。

⚠「基本情報」のメールアドレス = 院内へのお知らせメールの宛先です

ここに入れたメールアドレスは公開ページには表示されません。かわりに、患者から Web 予約が入ったときと患者が自分で予約をキャンセルしたときに、院内へお知らせメールを送る宛先として使われます。

未入力の場合は、院長(管理者)のログイン用メールアドレスが自動的に代わりの宛先になります。そのどちらも分からない状態だと、院内へのお知らせメールは作られず、届きません。

受付の担当者が毎日見るアドレス(代表アドレス・共有アドレスなど)を入れておくのが確実です。

⚠営業時間は施術枠の自動チェックには使われません

6-4 で登録する「施術枠」は、ここで入れた営業時間や休診日と自動で突き合わせません。営業時間外の枠を作るとその時間も患者に空きとして見えてしまいます。枠を登録するときに、時間帯を目で確認してください。

6-3. 院長が看護師(スタッフ)を招待する

  1. スタッフ管理を開くナビゲーションから「スタッフ」を開きます。
  2. 「スタッフを招待」を押す看護師のメールアドレス、ロール(「管理者」「医師」「スタッフ」から選択。看護師は「スタッフ」のままで OK)、雇用区分(任意。「雇用」または「業務委託」)を指定して招待します。表示された招待リンクを各看護師に渡します。
  3. 看護師が参加看護師が招待リンクを開き、名前とパスワードを設定すると、予約台帳・施術枠・患者の画面が使えるようになります。
  4. 公開ページで指名を受けるスタッフを設定する一覧の右端の「編集」を押し、「表示名(指名用)」(例: 鈴木)を入れ、「公開ページで指名可能にする」をオンにします。一覧の「指名」の列が「可」になれば設定できています。

ⓘロールの違い(かんたん)

管理者(owner・院長)=料金・メニュー・部屋・担当・スタッフ・クリニック設定まで全部さわれる。スタッフ(看護師)=予約台帳・施術枠・患者の日常業務ができる(設定は変更できない)。

⚠「公開ページで指名可能にする」がオフのスタッフは、患者側の空き時間に一切出ません

公開 Web 予約の空き時間は、「公開ページで指名可能にする」がオンのスタッフの枠だけから作られます。オフのままだと、そのスタッフの施術枠を登録しても患者側には空きが出ません(院内の予約作成では、オフのスタッフも担当に指定できます)。

また「表示名(指名用)」が空のスタッフは、患者が担当を選ぶボタンに出てきません(「指定なし」で予約された結果として割り当てられることはあります)。本名を出したくない場合は、苗字だけ・ニックネームなど患者に見せてよい表示名を入れてください。

6-4. 予約に必要なデータを登録する(院長)

予約を受け付けるには、あらかじめ次の 4 つを登録しておく必要があります。上から順に進めてください。4 つが全部そろって、はじめて患者側の画面に空き時間が出ます。

  1. 部屋を登録ナビゲーションの「部屋・担当」を開き、「部屋を追加」で施術室(例: 施術室1・施術室2)を登録します。使わなくなった部屋は「アーカイブ」で一覧から外せます(アーカイブした部屋の枠は患者側に出ません)。
  2. メニューを登録「メニュー」画面で、カテゴリ(例: アートメイク)と施術メニューを登録します。1 つのメニューにつき次を設定します。
    ・セッション構成= 施術の工程。ステップごとに種別(カウンセリング/施術/リタッチ)・所要分・+バッファ分を入れます。例: カウンセリング30分 → 施術120分(バッファ15分)
    ・説明(施術内容・注意事項・リスク副作用)
    ・「料金を表示」/「公開ページに掲載」/「指名を許可」のチェック
  3. 担当設定(誰がどのメニューをできるか)「部屋・担当」画面の下半分にある「担当設定」の表(縦=スタッフ、横=メニュー)で、担当できる組み合わせにチェックを入れます。チェックした瞬間に保存されます。
  4. 施術枠を登録「施術枠」画面の「施術枠を追加」で、担当スタッフ・部屋・種別・日付・開始・終了を指定します。種別は「受付枠(患者予約を受け付ける)」を選びます(「占有(休憩・準備など)」は予約を受けない時間です)。「曜日を指定して繰り返し登録」にチェックすると、曜日と終了日を指定して一括登録できます。

⚠担当設定を忘れると、公開ページの空き時間が 1 件も出ません

患者側に空き時間が出るのは、次の5 つすべてを満たしたときだけです。1 つでも欠けると、その時間は表示されません。

  • 担当スタッフが在籍中(スタッフ画面の状態が「有効」)
  • そのスタッフの「公開ページで指名可能にする」がオン
  • そのスタッフにそのメニューの担当設定のチェックがある ← いちばん忘れやすい
  • 枠の部屋がアーカイブされていない
  • 枠の種別が「受付枠」で、「所要+バッファ」の合計時間がその枠の中にすっぽり収まる

ⓘ「バッファ」は準備・片づけの時間です

バッファは、施術のあとの片づけ・清掃にかかる時間です。患者側の空き時間は「所要 + バッファ」が枠に収まる開始時刻だけを出すので、次の予約が背中合わせに入ることはありません。
例: 施術45分 + バッファ10分 = 55分を占有。10:00〜17:00 の受付枠なら、最後に出る開始時刻は 16:00(16:00+55分=16:55 で枠内)になります。

ⓘ院内予約は施術枠が無くても作れます

看護師が台帳に入れる予約(電話予約など)は、施術枠が無い時間にも作成できます(枠外でも警告なく作れます)。一方、患者側の Web 予約は「受付枠」の中にしか入りません。この違いを覚えておいてください。

なお問診は紙で運用します(MVP のスコープ判断)。「問診テンプレ」画面の登録は必須ではありません。くわしくは 未対応事項と注意点 を参照してください。

6-5. 公開 Web 予約をオンにする

6-4 のデータ登録が終わったら、患者向けの Web 予約を公開します。「クリニック設定」のいちばん下の「オンライン予約」で設定します。

  1. 「患者向けオンライン予約」をオンにするスイッチをオンにして「保存」を押します。公開ページの住所(URL)は 本番URL/c/スラッグ です(slug が sakura なら https://〜/c/sakura)。オフの間はこの URL を開いても「ページが見つかりません」になります。
  2. 「Web 予約の確定方法」を確認する選択肢は「院内で確認してから確定(推奨)」の 1 つだけです(表示されているまま、変更は不要です)。以前あった「メール確認後に自動確定」は選択肢から削除しました(理由は下の注意)。
  3. 「患者キャンセル期限(時間前まで)」を決める患者が自分でキャンセルできる締め切りです。初期値は 24(=予約の24時間前まで)。期限を過ぎると患者の画面には「キャンセル期限(24時間前)を過ぎています。クリニックへご連絡ください」と出て、電話での連絡になります。
  4. 保存して、公開ページを自分の目で見る「保存」を押したら、スマートフォンで 本番URL/c/スラッグ を開きます。メニューが並んでいる→「予約する」を押すと空き時間のボタンが出るところまで確認します。空き時間が出ないときは 6-4 の表で原因を探してください。ページの下には「予約の確認・変更・キャンセルはこちら」「プライバシーポリシー」「利用規約」へのリンクが出ます。
確定方法予約が入った直後の状態患者に届くメール院内でやること
院内で確認してから確定(推奨)「承認待ち」(この時点で枠は押さえられます)「ご予約を受け付けました(確認中)」台帳で内容を確認し「確定にする」を押す → 患者に「ご予約が確定しました」が届く

⚠「メール確認後に自動確定」は選択肢から削除しました

以前はもう一つの選択肢として「メール確認後に自動確定」が選べましたが、いまの実装には、患者が確認メールのリンクを押して確定させる手順がありません。選ぶと申し込みと同時に「確定」になり、いたずら予約や入力ミスもそのまま確定枠になっていました。

そのためこの選択肢は画面から削除しました。確認リンクの仕組み(リンクを押して初めて確定・30 分未確認で枠を自動解放)を実装したうえで、あらためて選べるようにする予定です。いま選べるのは「院内で確認してから確定(推奨)」だけです。

あわせて、公開予約には連続投稿を機械的に止める仕組み(レート制限)がまだありません。公開直後は台帳と院内へのお知らせメールを毎日見て、不審な予約はキャンセルする運用でカバーしてください(未対応事項と注意点)。

⚠「確定にする」を押すまで、患者に確定メールは届きません

「院内で確認してから確定」を選ぶと、Web からの予約は「承認待ち」で台帳に入ります。放置すると、患者は「確認中」のメールを受け取ったままになります。

Web 予約が入ると、6-2 で設定したメールアドレスに件名「【予約システム】新しい予約が入りました(要確認)」のお知らせが届きます(本文に「この予約は承認待ちです。管理画面での承認操作が必要です。」と入ります)。このメールが来たら、その日のうちに台帳で確認して「確定にする」を押す——という運用ルールにしてください。

6-6. 日常の操作:予約の変更と、患者への紐付け

公開 Web 予約を使うと、次の 2 つの操作を日常的に行うことになります。どちらも予約台帳で予約をクリックして開いた画面(右から出てくるパネル)から行います。

予約を変更する(日時・担当・部屋の付け替え)

  1. 台帳で予約を開く「予約台帳」で日付を選び、変更したい予約のチップ(色のついた四角)をクリックします。右から予約の詳細が出ます。
  2. 「予約を変更」を押す「予約を変更」ダイアログが開きます(説明文: 開始日時・担当・部屋を変更します。セッションは新しい開始時刻から自動で再配置されます)。
  3. 内容を直す「日付」「開始時刻」「担当」「部屋」を必要なだけ直します。カウンセリング→施術のような複数の工程は、新しい開始時刻から自動で並べ直されます。
  4. 「変更を保存」を押す「予約を変更しました」と表示されます。患者のメールアドレスが分かっている場合は、件名「【クリニック名】ご予約内容が変更になりました」のメールが届きます。

ⓘ変更できる予約・できない予約

変更できるのは「承認待ち」「確定」の予約だけです。「来院」「完了」「キャンセル」「不来院」になった予約は変更できません(その場合はキャンセルして作り直します)。また過去の日時には変更できません。変更先の時間に別の予約があると「指定の時間帯は部屋または担当が既に埋まっています」と出て保存されません。

公開 Web 予約を患者台帳に結びつける(名寄せ)

公開 Web 予約は、患者マスタ(患者台帳)と結びついていない状態で入ってきます。台帳のチップには患者名のかわりに 「(患者未設定)」 と表示されます。これを既存の患者と結びつける作業が「名寄せ」です。

  1. 台帳でその予約を開く「(患者未設定)」のチップをクリックすると、「ゲスト予約(患者マスタ未紐付け)」という見出しの下に、患者が申し込みのときに書いた申告氏名・かな・電話・メールが表示されます。
  2. 「患者に紐付け」を押す「患者に紐付け」ダイアログが開き、「既存患者の候補(n件)」として、電話番号やメールアドレスが近い既存患者が一致した理由のラベル付きで並びます。似た患者がいなければ「一致する既存患者の候補はありません」と出ます。
  3. 同じ人を選ぶ、または新規登録する候補の中に同じ人がいれば「この患者に紐付け」を押します。初めて来る患者なら「新規患者として登録」を押すと、申告内容(氏名・かな・電話・メール)そのままで患者を新しく作って紐付けます。
  4. 結果を確認する「患者に紐付けました」と出れば完了です。台帳のチップの表示が「(患者未設定)」から患者名に変わり、「患者」画面のその患者のページに、この予約が履歴として並びます。

⚠自動では統合しません。必ず人が確認してください

同姓同名の別人、家族で同じ電話番号を使っているケースなどを取り違えると、他人のカルテに施術履歴が混ざることになります。そのため、システムは候補を出すだけで自動では統合しません。候補が出ても、本人だと確認できないときは紐付けずに、来院時に確認してください。

☞送ったメールが届いているかを確認できます

「クリニック設定」のいちばん下に「通知の送信状況」があり、直近 50 件のメールの状態(待機中 / 送信中 / 送信済み / 失敗)と試行回数が見えます。「失敗」は自動での再送をあきらめた状態で、それ以上は自動で送られません。週に 1 回このリストを見る運用にしてください(STEP 8)。

6-7. 予約が作れることを確認する

ここまでで準備は完了です。看護師がログインし、予約台帳から予約を作れます。中核の流れは次のとおりです(本番での確認は STEP 7 のチェックリストで行います)。

施術が終わったら「完了にする」状態が「完了」になる
来院しなかったときは「不来院にする」状態が「不来院」になる(ここから先の状態には進めません)
日時・担当・部屋を変えるときは「予約を変更」(6-6)変更が保存され、患者に変更メールが届く
取りやめのときは「予約をキャンセル」→ 理由(任意)→「キャンセルを確定」状態が「キャンセル」になり、枠が空きに戻る。患者にキャンセルメールが届く

ⓘ予約の状態(ステータス)の呼び方

承認待ち(Web から入った、まだ院内が確認していない)→ 確定 → 来院 → 完了。取りやめは キャンセル、連絡なく来なかった場合は 不来院 です。
