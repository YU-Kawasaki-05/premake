## 5. 発生した問題と対処

| 問題 | 対処 |
|---|---|
| Next.js 16 の破壊的変更(middleware 廃止等) | 同梱 docs を精読し `proxy.ts` / async params / `revalidateTag` 第2引数等を AGENTS.md に記録 |
| supabase start が analytics/vector unhealthy で失敗(WSL2 定番) | config.toml で `analytics.enabled = false` |
| `supabase gen types --local` がコンテナ実行エラー | `--db-url` 直接続方式に変更(package.json 修正済み) |
| service_role にテーブル権限なし(42501) | マイグレーション末尾に grant + default privileges を追加 |
| Node 20 に native WebSocket がなく supabase-js が失敗 | **Node 22 必須**。`.nvmrc`(22)追加。nvm に v22.23.1 導入済み |
| Biome 2.5 と設定スキーマの不整合 | `biome migrate` + Tailwind ディレクティブの parser 設定 |
