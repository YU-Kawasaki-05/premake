## 1. S3 レビュー(subagent)と対応

予約ロジックを adversarial にレビューし、以下を修正:

| Severity | 指摘 | 対応 |
|---|---|---|
| HIGH | `searchPatients` の PostgREST `.or()` 文字列インジェクション | `lib/search.ts` の `sanitizeSearchTerm` で構文トークン(`,()*:."'\%_`)除去。患者一覧検索も同様に適用 |
| HIGH | ステータス遷移がサーバー未強制(cancelled 直接遷移でセッションが scheduled のまま=ゴースト予約が枠を占有) | `updateBookingStatus` で uuid 検証 + 現在ステータス取得 + `nextStatuses` による遷移規則強制 + cancelled は専用処理に限定 |
| MED | 新規患者が予約失敗時に孤児化 | `createBooking` に補償削除(`rollbackPatient`)を追加 |
| MED | `searchPatients` が PII 検索を監査記録せず | `patient.search` を recordAudit |
| MED | 台帳の日跨ぎセッションが負の高さ・誤配置 | 表示日 00:00 基準の通日分 + レンジclip(`place()`)に変更 |
| MED | 過去日時・duration<=0 を拒否せず | createBooking / createGuestBooking に過去日時・duration>0 ガード |
| LOW | cancelBooking の状態ガード無し | done はキャンセル不可・cancelled は冪等 |

**問題なしと確認された点**(維持): 越境IDORは clinic_id + RLS で不成立 / 二重取りは EXCLUDE で原子的防止 / is_ops 昇格不可 / JST→UTC 変換正確。
